远程访问与高级设置 可选

组网地址为 100.64.0.0/10 时开启。普通内网无需开启；设备需加入同一组网。

已有穿透，使用公网域名访问

域名需转发到资源共享端口，默认 18788。组网 IP 直连无需填写；这里不会自动创建穿透或更改防火墙。

穿透进程就在本机时留空。其他设备转发时，仅填写实际转发设备的 IP 或 CIDR 网段；代理应正确覆盖或追加 X-Forwarded-For。

权限与使用说明

默认只读，可查看、播放和下载。勾选“允许修改”后才开放上传、新建、移动、改名和删除。支持共享磁盘根目录；系统、配置和凭据内容会被隐藏，磁盘及共享根目录本身不能改名、移动或删除。

共享不开放工具箱管理、批处理、常用密码库或本机程序启动。普通 HTTP 仅用于可信内网或加密组网；公网访问使用 HTTPS，并保留访问口令。仅转发资源共享端口，不开放工具箱管理页。

目录、权限、口令和端口会保存在本机。关闭共享并保存后，下次启动也保持关闭。修改共享后，已登录设备需要重新登录。

修改后点击保存，才会应用到共享服务。
