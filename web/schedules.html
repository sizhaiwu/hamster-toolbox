计划任务

返回工具箱

工具箱后台运行时自动执行，关闭网页不影响。退出程序、关机或休眠时不执行，也不补跑。时间使用服务端电脑的本地时区。

使用说明

支持脚本、GET / POST 请求；可设置 1～8 个计划任务并发，超额任务自动排队；同一任务不重复执行。每个任务独立保留执行记录。

脚本拥有当前工具箱账户的权限。请只执行自己理解的脚本；配置与日志分别保存在用户数据目录，未加密，请勿放入笔记主密码等敏感信息。实时输出保留最后 64 KB，可在运行设置中调整每任务保留次数。

Windows 支持 PowerShell、CMD；Linux / macOS 支持 sh、bash。可调用工具箱 CLI 完成批处理。脚本结束状态由退出码判断，HTTP 默认 2xx 为成功，可选状态码和响应内容检查；重试默认关闭。Windows CMD 输出建议先使用 chcp 65001 >nul。

已准备系统信息、磁盘空间、GET 和 POST 四种示例，默认暂停。可先编辑再手动执行；POST 示例必须先换成自己的地址。

成功条件与失败重试（选填）

内容检查限响应前 1 MB；总超时包含全部尝试与等待。POST 重试需明确允许，避免重复操作。

目录互斥保护（选填）

工具箱 CLI 自动保护处理目录。自定义脚本可声明下方路径，相同资源发生读写冲突时等待；不声明的脚本无法自动判断其文件操作。

执行时间示例

    导入任务

    文件包含脚本、URL 和认证请求头等完整配置，请妥善保管，不要随意分享。导入工具箱后全部暂停，核对后再启用。

    支持工具箱完整格式和宝塔 JSON。仅导入 Shell / GET / POST；Linux Shell 保持 bash，不会转成 PowerShell，Windows 需自行准备 bash。网站与数据库备份等宝塔专属任务会列出跳过原因。

    完整格式保留全部配置，不含日志。宝塔格式导出基础配置；PowerShell / CMD、自定义 Cron、额外请求头或工作目录等无法转换时会列出原因。宝塔部分版本导入后会直接启用，且执行超时等行为由宝塔控制；下载前会再次提示。
