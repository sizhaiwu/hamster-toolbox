处理设置01 / CONFIGURE

请选择具体的资源文件夹；系统目录、盘符根目录和目录链接会被拦截。改名前请核对预览。

会列出资源子目录中的 TXT、URL、字幕、压缩包等非媒体文件；按类型判断，不代表一定无用。先核对预览，清理成功后再按剩余内容统计命名。输入目录本层的文件保留。

复制一段真实名称即可，例如 test 第001期。只把最后一段数字当作可变编号，其他文字保持精确匹配；替换中填写 {编号} 可以保留原编号。

例如：查找 ^test\s*第\d+期\s*，替换留空，可把 test 第001期 泡汤啦 改为 泡汤啦；替换填 新名称 则变为 新名称 泡汤啦。

表达式直接填写，不需要 /…/g；\d+ 匹配数字，\s* 匹配空白，(?i) 忽略大小写。使用 Go 正则语法，不支持前后断言；替换支持 ${1} 等捕获分组。

前后缀添加到文件扩展名之前；如果整段名称都被删空，预览会提示冲突，请填写替换名称。

仅处理输入目录下一层；符合所选编号格式的目录会自动跳过。起始填 99、位数填 3，即从 099 开始。

编号顺序与筛选

手动从 099 开始，100 个资源将编号为 099–198。点击续号会使用已有最大编号 + 1；预览会检查编号占用。

原文件保留，目录结构保持一致；已有目标会标记为冲突。

选择要压缩的格式（可多选）

目前支持 JPEG、PNG 和静态 WebP；动画 PNG / WebP 会跳过。PNG 的输出编码可在下方选择。补压 PNG 时选“仅 PNG”，同目录中的 JPG 就不会被处理。

建议 85–95，默认 90。不缩放、不裁剪，透明度使用无损编码；颜色为有损压缩，建议先检查几张结果。

质量越低通常体积越小。结果未变小时保留原文件，并跳过输出。

支持 MP4、MOV、TS、AVI、MKV、WebM 等常见视频。清除标题、注释、作者等标签，不重新编码，保留原文件。画面水印、字幕内容和片头广告无法通过清理元数据去除。

清理范围

输出到新目录，已有文件不覆盖。MP4 / MOV 使用 ExifTool；TS、AVI、MKV、WebM、MPEG、WMV、FLV 等使用 FFmpeg 流复制并保持后缀。重新封装可能改变文件体积、时间戳起点及容器标识，但不重新压缩音视频；不能保证所有标签为空。图片会移除拍摄、位置等可写元数据，也可能移除方向与色彩配置，请检查输出显示效果。原容器无法无损写回时报告失败，不自动转码。

原文件保留，不缩放、不降帧；结果未变小就跳过。HDR 暂不处理，内嵌字幕不输出。

怎么选？查看压缩率、耗时与详细说明

模式：高效适合日常省空间；兼容适合旧设备与分享；精细使用 CPU 慢速编码，适合愿意等待的存档任务。H.265 需要播放器支持，精细模式不保证每个文件更小。

加速：自动按 NVIDIA → Intel → AMD → CPU 选首个可用设备；指定显卡失败后转 CPU。CPU 通常耗时较长、占用较高；显卡需要对应硬件和驱动，不保证哪种设备一定压得更小。

实测参考：同一批约 921 MB 的视频，高效 H.265 + 均衡：

方式压缩后节省空间耗时
NVIDIA657 MB28.6%4分01秒
Intel417 MB54.7%7分30秒
CPU356 MB61.3%11分51秒

这组测试中：NVIDIA 最快；Intel 兼顾速度与体积；CPU 文件最小、耗时最长。各编码器画质没有完全对齐，不能只按大小判断优劣。

测试条件与画质数据

同一批 24 个 H.264 视频，画质基准 23、FFmpeg 9.0.2。硬件：RTX 4060 Ti、Intel UHD 770、Core i7-14700K。体积包含跳过项的原文件；耗时从开始编码到最后一个文件处理结束。

相同 9 段抽样 SSIM 均值：NVIDIA 0.9880、Intel 0.9837、CPU 0.9827。数值越接近 1，画面结构越相似，不能代替肉眼检查。结果取决于视频、硬件和设置；H.264、精细模式及 AMD 暂无这组实测。

文件处理：H.265 模式保留 SDR 的 10-bit 位深；H.264 转为 8-bit。奇数尺寸边缘最多补 1 像素。保留所有音轨，AAC 优先直接复制，其他音频转 AAC；附件不输出。

高级设置

数值范围 0–51；0 使用 CPU 最高画质，文件通常较大。两个过滤阈值设为 0 可处理全部支持的视频，不限制输出码率。

外观设置

文件信息包含文件名、时长、分辨率、大小、视频编码与帧率。支持中文文件名，原视频保留。预览阶段列出输出路径，点击执行后才生成图片。

临时密码不会自动保存；可通过“管理常用密码”加密保存。每个直接子目录、每个文件各生成一个压缩包，原资源保留。

编号、分卷大小与压缩强度

k / m / g 分别代表 KB / MB / GB。文件夹与文件各自编号；已压缩的图片和视频通常不必再压缩。

打包规则

不包含根目录的脚本、已有压缩包及工具输出目录。子目录内部的所有普通文件会完整保留，空目录也保留。相同目录列表和起始编号才会得到相同包名，增减目录后请重新检查预览。完成后自动校验，并在输出目录的“目录.txt”追加原名称对照；不会覆盖已有分卷。纯净打包不添加额外内容。

默认保留原包；开启后可选择移入回收站或永久删除。

支持格式与解压规则

使用完整版 7-Zip，支持 7z、ZIP、RAR 及其分卷。分卷放在同一目录，只处理首卷一次。保留包内目录结构，默认保留原压缩包；临时密码不会自动保存，常用密码可单独加密保存。先完整解压到临时目录，通过后再写出文件；取消时保留已完成的文件。
