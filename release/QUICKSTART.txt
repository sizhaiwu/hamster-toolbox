仓鼠工具箱

开始使用
1. 普通用户运行 *-setup.exe 安装包，通过桌面或开始菜单快捷方式打开。便携用户完整解压 Windows x64 完整 7z（或 ZIP），不要直接在压缩包内运行。
2. 便携目录保持两个 EXE、tools 和 desktop-runtime 文件夹及清单文件 在一起。源码 ZIP 和 *-update.zip 不能单独作为完整版使用。
3. 便携版双击 hamster-toolbox-desktop.exe，默认在独立桌面窗口操作，通用设置可切换浏览器，托盘可以再次打开或退出；需要控制台时使用 hamster-toolbox.exe 或 start-toolbox.cmd。
4. 左侧分为工作空间、文件整理、媒体处理、打包与解压，各组可折叠。批处理先“扫描并预览”，核对后“执行预览结果”。浏览磁盘则进入左侧“资源管理器”。

完整版适用于 Windows 10/11 64 位，包含批处理、7-Zip 与 mpv 所需组件。
不需要安装 Go、Python、Node.js 或配置 PATH。文件去重入口需要另行安装 Video Duplicate Finder，页面提供下载指引，支持图片和视频。

功能
- 私密笔记：本地主密码加密的富文本 / Markdown，支持图片文件附件、分类标签、历史、回收站、自动加密备份和完整迁移；支持分栏、同步滚动、全屏及列表折叠，底部附件可独立打开图片并缩放。
- 整理：目录统计命名、批量重命名、自定义目录编号与续号、媒体信息命名。
- 媒体：图片/视频元数据清理、图片/视频压缩、PDF 图册索引、视频缩略图拼图。视频可保留支持的原封装或统一 MP4；缩略图从内存管道读取单帧，定位失败时自动兼容重试。
- 压缩包：7-Zip 打包、附加文件、加密与分卷；解压 7z/ZIP/RAR、常见及仅剩 .001/.002 的分卷，默认重名自动改名；执行时显示当前包阶段进度。
- 浏览：多标签、快速访问、自然排序、大目录搜索、图标间距与分页记忆；文件夹上传/续传、校验复制与跨盘移动，支持右键操作与属性。
- 观看：图片缩放、连续浏览、视频悬停、预览缩略图和侧栏视频时长。时长按可视区域读取，不会先扫描全部视频。
- 悬浮：浏览器内多窗口，或本机 mpv 独立看图/播放、优先硬解，分别控制进度与声音；硬解取决于显卡和编码。mpv 中 Ctrl+1 设置 A、Ctrl+2 设置 B、Ctrl+3 取消 AB 重复；原生播放器面板可设置新窗口播完后停留、循环或关闭。
- 任务：不同工具可同时运行，各自保留预览、日志、进度和取消；同一工具同时一个任务，路径冲突仍会拦截。可按工具设置文件并发数，处理预览与日志支持全屏和收起。
- HDR：默认保留普通 HLG/HDR10。带杜比信息的 HLG 可显式选择“保留 HLG 基层”，会移除杜比动态信息。
- 计划任务：本机或远程管理员可定时运行脚本与 GET / POST，提供默认暂停的示例、脚本库、批量管理、导入导出和独立日志。
- 自动化：终端运行 hamster-toolbox.exe cli --help；CLI 默认预览，--execute 才执行。页面可复制命令。

私密笔记
从“工作空间 → 私密笔记”设置主密码，示例可直接修改或删除；需要时在“安全与备份”开启验证器。主密码无法找回，恢复码不能替代主密码。
修改后自动加密保存，以“已加密保存”和最后成功时间为准；离开电脑前锁定笔记库。默认刷新当前标签页可保持有效会话，手动锁定、超时或重启工具箱后需重新验证，可关闭刷新恢复。
升级或换电脑请导出含附件的完整加密备份；不要只复制 vault.json，单篇 Markdown 导出与附件下载是明文。共享访客不能访问私密笔记。

资源共享
在工具箱、资源管理器或笔记的“通用设置 → 共享与远程 → 配置共享与远程访问”添加目录或磁盘根目录、设置口令、明确只读/可修改，然后保存开启。默认关闭共享，新目录默认只读。
共享设置保存后会随工具箱启动恢复，最多 128 个目录。其他设备使用共享地址，默认端口 18788，不要分享带 session 的本机管理链接。
电脑、工具箱及资源磁盘须保持可用；HTTP 只用于可信内网或加密组网。外网 HTTPS 穿透需自行配置地址、可信代理和现有隧道，只转发共享端口，不开放管理端口。
共享设备输入正确口令后直接进入，使用浏览器预览，不启动主机上的 mpv 或其他本机应用。Cookie 未保存或页面加载失败时会显示原因。

完整远程工作台
在公共共享设置中另外开启完整工作台并设置独立管理员口令，通过共享地址的 /admin/ 登录。默认要求 HTTPS；可信内网或加密组网使用 HTTP 需明确开启。管理员可操作服务端账户有权限访问的全部资源，不受访客共享范围限制；笔记仍需主密码和动态码单独解锁。远程页面仅用浏览器预览，不启动服务端本机播放器。

文件与任务
- 托盘模式：运行 hamster-toolbox-desktop.exe，无控制台窗口；单击仓鼠图标打开页面，右键打开工具箱/资源管理器或退出。任务执行中请先完成或取消。关闭浏览器不会退出服务。
- 安装版可创建桌面与开始菜单快捷方式，默认按当前用户安装。安装时或“通用设置 → 启动”可选开机自启（默认关闭），登录后静默运行在托盘；卸载清理该安装的自启项，保留个人配置、私密笔记和任务历史。
- 工具箱页面底部“关于与更新”（资源管理器也在页面底部）显示当前版本，可查看 GitHub 最新正式版并打开版本列表。开发版会单独标注，检查失败会提示；检查不会自动下载或安装，更新前请结束任务并退出工具箱。
- 改名直接修改名称，没有全局撤销，先核对预览。
- 媒体处理通常输出副本，已有输出不直接覆盖；普通扫描不按历史永久排除源文件，覆盖回原图后仍可能再次压缩。
- 非媒体文件清理、解压成功后清理原包默认关闭。删除默认进入主机回收站；不可用则报错保留，不自动永久删除。
- 刷新/关闭浏览器不会停止已经提交的后台批处理；上传和网页播放会中断。关闭工具箱控制台会中断任务，已完成结果保留。顶部“任务历史”可载入参数；图片/视频压缩、元数据清理和视频缩略图可只重扫失败与未完成文件，再核对执行；单个文件从头处理，其他工具重新扫描完整范围。
- 设置和日志保存到当前用户配置目录，启动终端显示实际位置；工具参数、快速访问和共享会保留，开启恢复选项后可保存目录标签，前进后退历史仍属于当前浏览器会话。
- Windows 默认开启“记住此密码”，打包、解压分别加密记住最近输入或选择的密码；首次更新后需输入或选择一次。关闭可清除对应记忆，常用列表保留，保存结果显示在密码框下。加密绑定当前 Windows 账户，不能当作跨账户密码备份。
- 侧栏的结束状态在关闭对应提醒或进入工具页面后隐藏，日志、结果与历史保留；新窗口不重放旧提醒，已经打开的各页面分别接收后续完成通知。任务历史按目标工具判断是否可载入和重扫。

更新与排查
退出旧服务再覆盖更新文件；组件有变化时使用对应的新版完整版。不要删除 tools 的 DLL、字体、配置与许可文件。
组件异常时展开“本工具需要的程序”，点击“自动查找”并检查程序位置。
可运行 hamster-toolbox.exe -version、-check-tools、-self-test 诊断。
Linux/macOS 需从源码构建并安装本机组件，Windows tools 不能跨系统使用。
