仓鼠工具箱

第一次使用
1. 把 ZIP 完整解压到一个普通文件夹。
2. 双击 hamster-toolbox.exe，或 start-toolbox.cmd。
3. 浏览器会自动打开工具箱，选择左侧功能，再选择要处理的目录。
4. 点击“扫描并预览”，检查列表后点击“执行预览结果”。

完整版已包含十一项批处理工具所需组件，不需要安装 Go、Python、Node.js，也不需要配置环境变量。
“文件去重”是外部软件入口，需另行下载 Video Duplicate Finder；页面提供下载指引，支持视频和图片去重。
请保留 tools 文件夹及其中的全部文件，主程序和 tools 放在一起。
适用系统：Windows 10/11，64 位。

使用提醒
- 改名工具会直接修改名称，执行前请查看预览。
- 压缩、清理元数据、PDF、缩略图会显示输出位置，原文件保留。
- 目录统计命名的非媒体文件清理、解压成功后清理原包均默认关闭。开启后请核对待清理文件；永久删除不进入回收站。
- 显卡加速取决于硬件和驱动，不可用时可使用 CPU。回收站清理不支持的位置会保留原文件。
- 关闭浏览器页面后程序仍在运行；关闭工具箱控制台窗口才能退出。
- 程序使用本机浏览器操作，文件在本机处理，日常使用不需要联网。

更新
- 收到新版完整版时，完整解压到新文件夹即可，原有设置会保留。
- 收到 update.zip 时，先退出工具箱，再把里面的文件复制到原工具箱文件夹，替换同名文件；保留原来的 tools 文件夹。
- 如果发布者说明依赖已更新，请使用对应的新版完整版。

遇到问题
- 不要在 ZIP 内直接双击程序，请先完整解压。
- “本工具需要的程序”默认折叠，显示组件状态；需要时展开，点击“自动查找”恢复定位。
- 反馈问题时，请提供程序版本、操作步骤。导出日志含本地路径和文件名，发送前请自行脱敏，勿公开私人目录、资源名或密码。
- 工具参数和执行记录保存在当前 Windows 用户的配置目录中，更新程序不会覆盖它们。临时密码不保存，主动保存的常用密码按当前账户加密。
- 每项工具的输入、输出示例：https://github.com/sizhaiwu/hamster-toolbox/blob/main/docs/examples.md
