仓鼠工具箱

第一次使用
1. 把 ZIP 完整解压到一个普通文件夹。
2. 双击 hamster-toolbox.exe，或 start-toolbox.cmd。
3. 浏览器会自动打开工具箱，选择左侧功能，再选择要处理的目录。
4. 点击“扫描并预览”，检查列表后点击“执行预览结果”。

完整版已包含所需组件，不需要安装 Go、Python、Node.js，也不需要配置环境变量。
请保留 tools 文件夹及其中的全部文件，主程序和 tools 放在一起。
适用系统：Windows 10/11，64 位。

使用提醒
- 改名工具会直接修改名称，执行前请查看预览。
- 压缩、清理信息、PDF、缩略图会显示输出位置，原文件保留。
- 关闭浏览器页面后程序仍在运行；关闭工具箱控制台窗口才能退出。
- 程序使用本机浏览器操作，文件在本机处理，日常使用不需要联网。

更新
- 收到新版完整版时，完整解压到新文件夹即可，原有设置会保留。
- 收到 update.zip 时，先退出工具箱，再把里面的文件复制到原工具箱文件夹，替换同名文件；保留原来的 tools 文件夹。
- 如果发布者说明依赖已更新，请使用对应的新版完整版。

遇到问题
- 不要在 ZIP 内直接双击程序，请先完整解压。
- “本工具需要的程序”会提示组件状态，可点击“自动查找”恢复定位。
- 反馈问题时，请提供程序版本、操作步骤及“导出日志”保存的文件。
- 所有参数和记录保存在当前 Windows 用户的配置目录中，更新程序不会覆盖它们。
