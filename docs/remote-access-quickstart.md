# 不同网络访问：新手教程

[文档目录](README.md) · [资源管理器](file-browser.md) · [HTTPS 与代理设置](remote-access.md)

目标：电脑在家，手机使用流量或其他 Wi-Fi，也能查看电脑上的图片、视频和文件。下面任选 **xEdge 或 ZeroTier** 一种方式，把两台设备放进同一个虚拟局域网，再用浏览器访问工具箱的共享服务。一般不需要公网 IP、域名或路由器端口映射。

- **服务端**：存放文件、运行仓鼠工具箱的电脑。
- **访问端**：手机、平板或另一台电脑。只需组网客户端和浏览器，不必再装一份工具箱。
- **访问地址**：`http://服务端的组网IPv4:共享端口/`。用电脑的地址，不是手机自己的地址。

本文使用新安装默认端口 `18788`；如果你保存过其他端口，以下地址都换成实际值。所有 IP 均为虚构示例，不能直接当作你的地址使用。

## 第一步：先在电脑开启资源共享

1. 启动工具箱，进入左侧 **资源管理器 → 内网共享设置**。
2. 添加一个用于试用的资源目录，先保持只读。设置至少 8 字符的共享口令。
3. 确认共享端口，勾选开启共享，点击“保存并应用”，看到已开启状态。
4. 在服务端电脑用浏览器打开 `http://127.0.0.1:18788/`，输入共享口令，确认能看到目录。先排除工具箱未启动或端口错误，再配置组网。

这里的共享口令由你在工具箱设置，和 xEdge、ZeroTier 的账号密码不是同一个东西。不要使用启动终端里带 `session` 的管理链接作为远程访问地址。

## 第二步：任选一种组网方式

| 方式 | 两台设备怎样接入 | 下一步 |
| --- | --- | --- |
| xEdge | 将电脑和手机作为终端接入同一个安全内网 | [xEdge 步骤](#方式一xedge-添加终端) |
| ZeroTier | 两台设备加入同一个 Network ID，并在控制台授权 | [ZeroTier 步骤](#方式二zerotier-加入虚拟网络) |

这些是第三方产品的接入方法，入口名称、可用客户端、设备数量和服务限制以其当前官网为准；工具箱不捆绑或代办账号，也不保证所有网络都能直连。第一次先选一种，不需要同时开启多个组网客户端。

### 方式一：xEdge 添加终端

**1. 注册并打开控制台。** 从 [xEdge 官网](https://xedge.cc/) 登录，建立自己的安全内网。设备接入也就是把设备添加为终端；按当前控制台的添加/接入终端引导，选择对应系统。基础流程见 [xEdge 官方快速上手](https://doc.xedge.cc/快速上手)。

**2. 添加服务端电脑。** 从 [官方下载页](https://xedge.cc/download) 安装电脑客户端，按引导完成系统服务安装和认证入网，使用管理该安全内网的账号认证。Windows 的详细操作见 [官方安装指引](https://doc.xedge.cc/zh/安装指引/Windows安装指引)。

**3. 添加手机。** 在手机安装对应客户端，开启组网并完成同一安全内网的账号认证。首次连接可能需要你确认系统 VPN 配置，具体看 [Android 指引](https://doc.xedge.cc/zh/安装指引/Android安装指引)或 [iOS 指引](https://doc.xedge.cc/zh/安装指引/iOS安装指引)。手机也必须入网，不能只在电脑安装。

**4. 找到电脑的组网 IPv4。** 在终端列表/客户端确认电脑和手机均已接入，查看或复制电脑的组网 IP。不要复制终端名称、认证链接或手机 IP。

**5. 配置工具箱允许访问。** 如果客户端地址属于 `100.64.0.0/10`（`100.64.0.0–100.127.255.255`），在工具箱共享设置的“远程访问与高级设置”勾选 **允许虚拟组网访问**并保存。该开关仅放行这个地址段；看到 `100` 开头不能一概判断。使用普通私有 IPv4 网段时按下文地址规则处理。

**6. 从手机打开。** 假设电脑组网地址为 `100.64.0.10`，在手机浏览器地址栏输入：

```text
http://100.64.0.10:18788/
```

出现“仓鼠文件共享”登录页后输入工具箱共享口令。xEdge 客户端必须保持连接；不要把地址填到搜索框后仅搜索。

本教程只让安装客户端的两台设备互访，不需要配置子网路由、出口节点或开放公网端口。若你额外开启了 xEdge 网络访问控制，需确认手机到电脑的 TCP 共享端口被允许；规则含义见 [官方网络功能更新说明](https://doc.xedge.cc/Release)。

### 方式二：ZeroTier 加入虚拟网络

**1. 创建私有网络。** 进入 [ZeroTier Central](https://central.zerotier.com/)。新版按引导创建组织，在 Networks 下找到网络；旧版控制台使用“Create A Network”。保持网络私有，复制网络的 **16 位 Network ID**。不要把设备自己的 Node ID 当作 Network ID。[官方创建网络教程](https://docs.zerotier.com/quickstart/)

**2. 电脑加入网络。** 从 [官方下载页](https://www.zerotier.com/download/) 安装客户端。Windows 在托盘图标中选择 **Join New Network…**，粘贴 Network ID 并加入。

**3. 手机加入同一个网络。** 安装手机对应客户端，通过添加网络入口填写相同 Network ID，开启连接，按系统提示配置 VPN。下载入口同上，具体按钮以手机客户端为准。

**4. 在控制台授权两台设备。** 新版在 **Member Devices** 中找到待授权设备，选择 **Authorize**；旧版在 **Members** 中勾选设备旁的 **Auth?**。核对是自己的电脑与手机。只加入网络但未授权时，两台设备不能正常互访。[官方成员管理说明](https://docs.zerotier.com/networks/)

**5. 复制电脑的组网 IPv4。** 在成员列表查看电脑的 **ZT IP / Managed IP**。假设为 `10.147.17.10`，手机浏览器打开：

```text
http://10.147.17.10:18788/
```

输入工具箱共享口令，即可访问。不要用 Network ID、设备 ID 或手机 IP 拼地址。

**6. 对照地址段设置工具箱。** 常见的 `10.*`、`172.16.*–172.31.*`、`192.168.*` 私有 IPv4 已在工具箱内网来源范围中，不需要开启仅针对 `100.64.0.0/10` 的开关。若自行配置为该 `100.64` 地址段，才启用“允许虚拟组网访问”。不要为连接成功而随意分配公网 IPv4；本教程使用私有 IPv4，不涉及 IPv6 配置。

## 第三步：确认真的可以跨网络访问

1. 保持服务端电脑开机、工具箱运行、资源磁盘在线，组网客户端保持连接。
2. 手机关闭 Wi-Fi、改用流量，并保持所选组网客户端已连接；另一台电脑也可使用不同网络测试。
3. 重新打开 **电脑的组网 IP + 共享端口**，登录并试着看一张图片、播放一段视频或下载小文件。
4. 成功后可将这个共享地址加入浏览器书签。需要上传、移动、改名或删除时，再回服务端明确开启对应目录的“允许修改”。

账号/套餐、直连或中转以及两端网络会影响速度，大视频不保证达到家中局域网速度。变更共享端口或电脑组网地址后，书签也需要更新。

## 新手容易混淆的设置

| 项目 | 组网 IP 直连时怎样填 |
| --- | --- |
| 共享端口 | 工具箱实际保存的端口，新安装默认为 `18788` |
| 外网访问地址（HTTPS） | 留空；只有另外部署 HTTPS 域名代理时才填 |
| 可信代理 IP | 留空；组网设备互访不等于反向代理，不要填写手机 IP |
| 允许虚拟组网访问 | 仅在实际来源属于 `100.64.0.0/10` 时开启 |
| 手机访问地址 | `http://电脑组网IPv4:共享端口/`，包含 `http://` 和端口 |
| 管理页地址 | 仅本机使用，不映射，不发送给其他设备 |

同一虚拟网络的设备间使用 HTTP，其传输保护依赖组网通道；不要把此 HTTP 地址改成直接公网暴露。想让没有组网客户端的设备通过域名访问，另见 [HTTPS 域名与可信代理](remote-access.md#https-域名和可信代理)。

## 连不上时按顺序排查

| 现象 | 先检查什么 |
| --- | --- |
| 服务端用 `127.0.0.1:端口` 都打不开 | 工具箱是否运行、共享是否已开启、端口是否正确或被占用 |
| 手机看不到电脑或电脑不在线 | 两台设备是否接入同一网络；ZeroTier 是否完成两台设备授权 |
| 浏览器一直超时 | 是否填了电脑的正确 IP；客户端是否连接；网络规则及主机防火墙是否允许 TCP 共享端口 |
| 提示来源被拦截 | 实际来源是否属于 `100.64.0.0/10`，对应开关是否已开启并保存 |
| 登录页出现但口令失败 | 输入工具箱的共享口令，不是组网账号密码；修改共享配置后需要重新登录 |
| 登录成功但列表为空 | 目录是否已添加、磁盘是否在线、是否具有读取权限 |
| 加载慢或视频卡顿 | 中转带宽、服务端上传速度、手机网络、浏览器编码；先试小文件或下载原视频 |
| 手机 VPN 开关自动关闭 | 是否与其他 VPN 冲突；不要同时开启两种组网客户端。[ZeroTier 官方说明](https://docs.zerotier.com/faq/android-badtoggle/) |

如需调整防火墙，只允许该程序/共享端口及实际需要的虚拟网络来源，不要关闭整个防火墙。手机休眠后的连接状态、设备数量、客户端支持与服务规则以各平台当前官方说明为准。本文按官方指引整理，未代替你注册账号、安装客户端或修改现有网络配置。
