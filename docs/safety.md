# 安全与数据保护

[文档目录](README.md)

[返回首页](../README.md)

工具箱按当前系统用户的权限运行，不需要管理员权限。请使用具体的资源目录，并在执行前核对预览。路径防护用于减少误操作，不是隔离恶意程序的沙箱。

## 路径保护

扫描和执行共用路径检查，覆盖目录统计命名、批量改名、连续编号以及媒体处理、打包和解压：

- 拒绝盘符根目录、网络共享根目录、管理共享、设备路径和备用数据流路径。
- 拒绝 Windows、Program Files、ProgramData、系统恢复与启动目录、回收站及磁盘系统文件。
- 拒绝用户目录根目录、其他用户目录、应用配置与常见凭据目录。整个临时目录不能处理，其下单独的临时资源文件夹可以使用。
- 保护正在运行的工具箱程序目录和本次启动的数据目录；包含这些目录的上级目录也不能整体处理。源码仓库中的程序、组件和配置因此不会随资源一起被改名。
- 拒绝包含符号链接或目录联接的选定路径；扫描遇到这些链接会跳过。Windows 短路径别名会解析为实际路径后检查。
- 改名只能发生在源文件或目录的同一父目录内；生成的文件必须位于指定输出范围。

普通的系统盘资源子目录仍可使用。若某个资源目录中同时放着工具箱，请把资源和工具箱分开放置。

打包的“附加文件”只读取用户逐项指定的普通文件，不改名或删除来源，因此不套用系统目录、其他用户目录等写操作限制。Windows 仍须允许当前账户读取；文件夹、目录链接、设备路径及备用数据流路径仍会被拒绝。附加文件复制到临时目录后打包，不与来源建立硬链接；执行前后复核文件标识、大小和修改时间，来源变化时要求重新扫描。

预览记录输入目录与处理源的文件标识、实际路径；执行前及逐项处理时再次检查。文件或目录被替换、链接改向或路径越界会停止相应处理，要求重新扫描。并发修改仍可能发生在检查与系统调用之间，因此处理期间不要移动资源目录，也不要让其他程序同时修改同一批文件。

## 保留原文件与清理原包

媒体处理默认输出副本。一般输出采用独占创建，已有文件不会被直接截断。批量改名直接修改原名称，不是备份，也没有全局撤销功能。

解压默认保留原包、重名自动改名。用户可明确选择覆盖，覆盖仅替换普通文件。包内绝对路径、上级跳转、链接和不合法 Windows 名称会被拦截。先完整解压并检查，再发布结果；发布过程中失败或取消可能保留已经写出的文件。

“解压成功后清理原压缩包”默认关闭。开启时初始选择回收站；永久删除需另外选择。仅完整解压且全部内容写出后，才清理确认由本包使用的原文件及实际分卷。跳过内容、密码错误、损坏、取消或分卷归属不明时保留原包。

目录统计命名的“清理图片、视频、音频之外的文件”也默认关闭，初始清理方式为回收站。仅处理预览列出的普通文件，不删除目录，不跟随链接；以文件标识、大小和修改时间复核。扩展名不在媒体清单中不代表文件一定无用，文档、字幕和压缩包会列入，因此必须先核对预览。清理后重新核对统计，异常时停止后续改名，已经清理的文件不会自动撤销。

回收站直接调用 Windows 自带的 `IFileOperation`，无需 Python、PowerShell 模块或额外安装。当前实现支持 Windows 10/11 64 位上的本地固定磁盘；网络位置、移动磁盘、系统策略或权限不支持时报告失败，未完成的原包保留，不会自动改为永久删除。系统回收站仍受磁盘空间、容量和用户设置约束，不能代替备份。已验证当前测试机的实际移入与还原，尚未覆盖所有 Windows 版本及企业策略组合。

## 本地接口与密码

管理服务始终仅监听 `127.0.0.1`，操作接口要求当前启动生成的随机会话令牌与 POST 请求。页面不加载第三方脚本，文件名通过文本节点显示。外部工具以独立参数启动，不把资源名称拼成 Shell 命令。

内网文件共享默认关闭，需在本机设置资源目录和访问口令后开启独立 IPv4 端口；开启并保存后会随工具箱启动恢复，关闭并保存后停止自动共享。每次启动重新检查目录权限与安全边界，不可用目录保留配置但不向访客开放。访客仅访问选定共享范围，不开放本机批处理、密码库和共享管理接口；每个目录默认只读，修改权限需显式开启。共享会话使用 HttpOnly、SameSite=Strict Cookie，同源 POST 校验防止跨站写入；停止共享关闭连接，更新配置使旧登录失效。普通 HTTP 传输未加密，仅用于可信内网或加密组网；现有 HTTPS 穿透需配置允许的外部地址和可信代理，代理头本身不会授予访问权限。组网地址需要单独开启；共享认证和目录边界仍然生效。见[远程访问](remote-access.md)。[完整边界与操作规则](file-browser.md)

本机文件浏览可以只读列出磁盘及普通可读取路径，写入仍执行受保护路径检查。上传、改名不覆盖目标；复制/移动遇到同名目标时需明确选择，替换前校验副本并备份原文件。合并目录失败或取消会保留已完成的文件，不提供整棵目录回滚。删除默认使用系统回收站或废纸篓；永久删除须单独选择。文件操作复核文件标识与元数据；没有磁盘保留配额，内网写权限只应交给信任的用户。

临时输入的压缩密码不写入设置和执行记录。主动保存的常用密码使用 Windows DPAPI 按当前账户加密，更换账户需重新添加。用户自行复制的命令、外部程序的进程参数以及已取得当前账户权限的软件，不在此保护边界内。

[任务历史](task-history.md)保存私人路径、参数和尾部日志，仅本机管理会话及明确开启的远程管理员可读取。定向重扫重新检查当前文件及目标，不重放旧执行计划；不会自动启动任务或撤销已完成操作。导出日志供他人查看前请自行脱敏，清理历史不删除资源文件。

## 使用边界

工具箱与 FFmpeg、ImageMagick、ExifTool、7-Zip 等外部组件以当前用户权限运行，不隔离不可信文件。下载组件时会按固定清单验证 SHA256；用户自行选择的程序路径不等于经过安全审计的软件。请从官方来源获取组件，并随更新检查组件版本。

文件去重是打开外部软件的入口，其扫描、删除和设置由外部软件自行管理，工具箱的目录保护不适用于其窗口内的操作。

批量解压和批量转码没有操作系统级的磁盘容量或内存配额。异常膨胀的压缩包或超大媒体可能耗尽可用空间；解压预览会展示包内声明的文件体积，但这不是对恶意压缩包的资源限制。资源管理器的兼容预览另设输入、尺寸、时间、线程、并发及缓存限制，使用文件句柄并禁止解码器访问其他协议，但这些限制仍不是进程沙箱。复制到命令行执行的命令也不会经过工具箱的逐项安全检查。

重要资源应另有备份。不建议以管理员身份运行，路径保护也不能保证消除恶意本地进程或同时修改目录造成的所有竞态。

资源管理器允许显式共享磁盘或文件系统根目录（默认只读），过滤受保护系统、配置、凭据及工具箱内容，同时拒绝直接读取这些路径；共享根目录本身不能改名、移动或删除。此例外仅用于资源共享，批量处理入口仍拒绝根目录。Linux/macOS 同样只在明确选择替换并备份时处理同名目标，废纸篓不可用时保留源文件；详细限制见 [platforms.md](platforms.md)。

## 私密笔记

标题、正文、附件索引、历史、回收站与笔记设置加密保存；图片和文件独立加密。笔记对本机管理会话和明确开启的远程管理员开放，均须另行解锁，普通文件共享访客不能访问。完整备份仍是密文；单篇 Markdown 导出和附件下载是明文。

当前开发版提供[完整远程工作台](remote-workspace.md)，默认关闭，使用独立管理员口令、HttpOnly Cookie 和请求校验，不对外暴露本机管理令牌。远程管理员具有服务端工具箱管理权限，不受普通文件共享目录范围限制。默认要求 HTTPS；只有明确允许后才接受可信内网或加密组网 HTTP，HTTP 自身不会加密口令和笔记。每个浏览器独立解锁笔记，修改共享配置、退出或会话到期后撤销相应管理员访问。

刷新恢复只在当前标签页保留临时会话凭证，不保存主密码、解密密钥或明文笔记；每次恢复由后端验证。手动锁定、空闲超时和服务重启使旧会话失效；关闭标签页后后台按空闲设置清理，离开电脑前请手动锁定。

单篇编辑锁只防误改；动态码是应用层验证，不能作为独立的离线加密因素。主密码不能重置，恢复码不能替代主密码；不要把唯一的主密码只存进该笔记库。当前没有独立第三方密码学安全审计，也不能防御已被控制的电脑和恶意浏览器扩展。

迁移请用含附件的完整加密备份，有附件时只复制 `vault.json` 会缺少文件。升级、清理数据和卸载前应保留独立备份，自动备份不是零丢失保证。配置目录、备份、草稿、动态码密钥及恢复码不得提交到仓库或公开分享。[笔记安全与备份](private-notes.md)
