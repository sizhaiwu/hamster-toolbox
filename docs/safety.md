# 安全与数据保护

[返回首页](../README.md)

工具箱按当前 Windows 用户的权限运行，不需要管理员权限。请使用具体的资源目录，并在执行前核对预览。路径防护用于减少误操作，不是隔离恶意程序的沙箱。

## 路径保护

扫描和执行共用路径检查，覆盖目录统计命名、批量改名、连续编号以及媒体处理、打包和解压：

- 拒绝盘符根目录、网络共享根目录、管理共享、设备路径和备用数据流路径。
- 拒绝 Windows、Program Files、ProgramData、系统恢复与启动目录、回收站及磁盘系统文件。
- 拒绝用户目录根目录、其他用户目录、应用配置与常见凭据目录。整个临时目录不能处理，其下单独的临时资源文件夹可以使用。
- 保护正在运行的工具箱程序目录和本次启动的数据目录；包含这些目录的上级目录也不能整体处理。源码仓库中的程序、组件和配置因此不会随资源一起被改名。
- 拒绝包含符号链接或目录联接的选定路径；扫描遇到这些链接会跳过。Windows 短路径别名会解析为实际路径后检查。
- 改名只能发生在源文件或目录的同一父目录内；生成的文件必须位于指定输出范围。

普通的系统盘资源子目录仍可使用。若某个资源目录中同时放着工具箱，请把资源和工具箱分开放置。

打包的“附加文件”只读取用户逐项指定的普通文件，不改名或删除来源，因此不套用系统目录、其他用户目录等写操作限制。Windows 仍须允许当前账户读取；文件夹、目录链接、设备路径及备用数据流路径仍会被拒绝。附加文件复制到临时目录后打包，不与来源建立硬链接；执行前后复核文件标识、大小和修改时间，来源变化时要求重新扫描。

预览记录输入目录与处理源的文件标识、实际路径；执行前及逐项处理时再次检查。文件或目录被替换、链接改向或路径越界会停止相应处理，要求重新扫描。并发修改仍可能发生在检查与系统调用之间，因此处理期间不要移动资源目录，也不要让其他程序同时修改同一批文件。

## 保留原文件与清理原包

媒体处理默认输出副本。一般输出采用独占创建，已有文件不会被直接截断。批量改名直接修改原名称，不是备份，也没有全局撤销功能。

解压默认保留原包、重名自动改名。用户可明确选择覆盖，覆盖仅替换普通文件。包内绝对路径、上级跳转、链接和不合法 Windows 名称会被拦截。先完整解压并检查，再发布结果；发布过程中失败或取消可能保留已经写出的文件。

“解压成功后清理原压缩包”默认关闭。开启时初始选择回收站；永久删除需另外选择。仅完整解压且全部内容写出后，才清理确认由本包使用的原文件及实际分卷。跳过内容、密码错误、损坏、取消或分卷归属不明时保留原包。

目录统计命名的“清理图片、视频、音频之外的文件”也默认关闭，初始清理方式为回收站。仅处理预览列出的普通文件，不删除目录，不跟随链接；以文件标识、大小和修改时间复核。扩展名不在媒体清单中不代表文件一定无用，文档、字幕和压缩包会列入，因此必须先核对预览。清理后重新核对统计，异常时停止后续改名，已经清理的文件不会自动撤销。

回收站直接调用 Windows 自带的 `IFileOperation`，无需 Python、PowerShell 模块或额外安装。当前实现支持 Windows 10/11 64 位上的本地固定磁盘；网络位置、移动磁盘、系统策略或权限不支持时报告失败，未完成的原包保留，不会自动改为永久删除。系统回收站仍受磁盘空间、容量和用户设置约束，不能代替备份。已验证当前测试机的实际移入与还原，尚未覆盖所有 Windows 版本及企业策略组合。

## 本地接口与密码

服务仅监听 `127.0.0.1`，操作接口要求当前启动生成的随机会话令牌与 POST 请求。页面不加载第三方脚本，文件名通过文本节点显示。外部工具以独立参数启动，不把资源名称拼成 Shell 命令。

临时输入的压缩密码不写入设置和执行记录。主动保存的常用密码使用 Windows DPAPI 按当前账户加密，更换账户需重新添加。用户自行复制的命令、外部程序的进程参数以及已取得当前账户权限的软件，不在此保护边界内。

## 使用边界

工具箱与 FFmpeg、ImageMagick、ExifTool、7-Zip 等外部组件以当前用户权限运行，不隔离不可信文件。下载组件时会按固定清单验证 SHA256；用户自行选择的程序路径不等于经过安全审计的软件。请从官方来源获取组件，并随更新检查组件版本。

文件去重是打开外部软件的入口，其扫描、删除和设置由外部软件自行管理，工具箱的目录保护不适用于其窗口内的操作。

目前没有为外部解压和转码进程设置磁盘容量、内存或运行时间配额。异常膨胀的压缩包或超大媒体可能耗尽可用空间；解压预览会展示包内声明的文件体积，但这不是对恶意压缩包的资源限制。复制到命令行执行的命令也不会经过工具箱的逐项安全检查。

重要资源应另有备份。不建议以管理员身份运行，路径保护也不能保证消除恶意本地进程或同时修改目录造成的所有竞态。
