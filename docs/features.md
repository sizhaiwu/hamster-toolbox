# 完整功能清单

[文档目录](README.md) · [操作指南](usage.md) · [输入输出示例](examples.md)

当前提供 **11 项批处理工具、1 个外部去重入口，以及资源管理器和私密笔记**。以下以当前源码为准，正式发布状态见[版本变更](../CHANGELOG.md)。

## 整理与处理

| 工具 | 能做什么 | 输出或边界 |
| --- | --- | --- |
| 目录统计命名 | 统计图片/视频/音频数量与大小，兼容旧统计写法，可选清理非媒体文件 | 直接改目录名，清理默认关闭 |
| 批量重命名 | 普通文字、编号示例、正则、前后缀，选择文件或目录 | 直接改名，冲突不覆盖 |
| 目录批量编号 | 仅编号、名称与编号、自定义模板、起始值、位数与续号 | 处理直接子目录，可生成 `029 - 名称` |
| 媒体信息命名 | 用尺寸、时长、大小等更新文件名描述 | 直接改名，需要 FFprobe |
| 清理元数据 | 按支持格式清理图片和视频信息 | 输出副本，不去除画面水印或片头广告 |
| PDF 图册索引 | 生成子目录封面和中文标题图册 | 输出 PDF，不是可点击书签或可选择文本 |
| 压缩图片 | JPEG、PNG、静态 WebP；格式筛选、画质、PNG 编码方案 | 不缩放；PNG 可保留名称而改用 WebP 编码，注意软件兼容 |
| 压缩视频 | 三种模式、画质预设、硬件/CPU 选择及失败回退 | 不主动降尺寸/帧率，输出副本，未变小不发布 |
| 视频缩略图 | 定时取帧拼图，调整行列、宽度、边距、时间和文件信息；定位失败自动兼容重试 | 输出预览图片，不改原视频，不复用旧帧冒充成功 |
| 打包资源 | 7-Zip 加密、分卷、附加文件、独立编号和结果校验 | 默认 `0utput_7z`；目录/文件分别编号，原资源保留 |
| 解压资源 | 7z/ZIP/RAR/TAR、复合 TAR、常见归档及仅剩 `.001/.002` 的字节分卷；显示当前包阶段进度 | 默认按包分目录、重名自动改名、保留原包；清理原包需自行开启 |
| 文件去重 | 检查或打开 Video Duplicate Finder，提供下载指引 | 第三方软件另装，图片/视频结果由用户核对，不自动删除 |

具体格式、参数、跳过规则和输出位置见[使用指南](usage.md)及 [CLI 参数手册](cli-reference.md)。

## 资源管理器

- 多标签右键菜单及拖动排序、快速访问拖动排序与保存、同名目录的盘符/父路径区分、自然数字排序、正倒序、分页记忆、图标大小与项目间距、折叠导航和返回顶部。
- 单击选中、双击/Enter 打开，Ctrl/⌘ 多选、Shift 连选、选择模式、右键菜单和属性；返回目录恢复滚动、分页和视图。
- 新建、文件/文件夹上传、断点续传、复制/剪切/粘贴、同盘及跨盘移动、改名、下载、删除；本机可打开系统文件管理器或选择其他应用打开文件。
- 图片缩放与拖动，跨页连续浏览；视频原始/兼容播放和悬停短片；预览提供底部缩略图与侧边同类文件列表。
- 图标、列表及预览侧栏显示视频时长；只探测可视区域附近的视频，最多 2 个并发，缓存复用。属性显示尺寸、时长及可读取的编码信息。
- 浏览器内同时悬浮多个图片/视频，独立调整位置、大小、置顶和播放状态；本机 mpv 在浏览器外独立显示图片/视频，优先硬解。硬解取决于编码、显卡和驱动。
- 常见音频、PDF、文本和代码预览；Office 文档、压缩包等下载后使用应用打开。支持格式及性能代价见[媒体预览](media-preview.md)。

## 共享、自动化与设置

多个目录或磁盘根目录共享，分别设置只读/可修改；输入正确口令即可进入，保存开启后随服务启动恢复，适配电脑、手机和平板。支持已有加密组网、HTTPS 穿透/代理；不代办隧道或证书，不对外开放管理端口。

v0.2.4 增加[完整远程工作台](remote-workspace.md)：使用共享端口上的 `/admin/` 和独立管理员口令访问整个工具箱、服务端资源管理器及私密笔记。默认关闭、默认要求 HTTPS，可信内网或加密组网的 HTTP 需要明确开启；笔记仍分别验证主密码与动态码，普通文件共享访客不能获得管理员权限。

CLI 默认预览，`--execute` 才执行；页面可复制完整 CLI，部分单项可导出底层程序命令，底层命令不包含工具箱的完整保护流程。去重 CLI 仅检查或启动外部 GUI。

工具参数、依赖路径、快速访问及共享设置持久化。Windows 常用密码列表按账户加密；Linux/macOS 可临时输入密码，尚无等价密码库。

## 平台与限制

Windows 10/11 x64 可分发完整安装包与便携 ZIP，桌面/开始菜单快捷方式使用无控制台的托盘启动文件；可选当前用户登录自启，默认关闭。见[安装说明](installation.md)。Linux/macOS 从源码构建并安装本机组件，当前不含 Windows 托盘与安装器。跨平台编译通过不代表所有桌面功能、驱动和编码均已真机验证。

大目录分批读取完整项目后搜索、排序和分页，可取消读取，并可搜索子目录；时长不参与排序。刷新不会停止后台批处理；上传中断后重新选择相同文件可续传，网页播放器会中断。关闭服务会中断任务；[任务历史](task-history.md)保留升级后的网页执行结果，四类独立媒体任务可重新预览失败和未完成文件，单个文件从头处理。改名没有全局撤销。见[常见问题](faq.md)与[安全说明](safety.md)。

## 通用设置与性能

工具箱、资源管理器和笔记共用通用设置。“共享与远程 → 配置共享与远程访问”统一管理文件共享目录、端口、访客口令和完整远程工作台；普通文件共享访客没有这些管理权限。

不同批处理工具可以同时运行，预览、日志和取消互相独立；同一工具同时一个任务，左侧显示进度。同目录修改及重叠输出有冲突保护。图片压缩、元数据清理、视频缩略图可设置 1–8 个独立文件并发，视频压缩可设置 1–3 个，默认均为 1，按工具保存；改名、目录编号、PDF、打包和解压仍按原顺序处理。独立编码进程内部还可能使用多个线程。

本机资源目录右键可直接选择工具箱功能并带入目录，仍需预览和确认执行。工具箱页面底部“关于与更新”显示当前版本、最新正式版和版本列表入口，检查不会自动下载安装。任务完成提醒在工具箱与本机资源管理器共用，多页打开时各页独立提醒，多个完成任务依次显示。通用设置可选择默认播放器、自动播放、静音、播放位置记忆、重启恢复标签、字号及缩略图磁盘缓存上限；缓存默认 256 MB，可关闭或清理。共享访客不读取本机设置和任务状态。

## 私密笔记

[私密笔记](private-notes.md)支持富文本 / Markdown、图片与文件附件、初始化示例、分类标签和置顶、正文查找、历史版本、加密回收站、自动加密备份与完整迁移，以及字号和分栏记忆。内容本地加密，可选验证器；支持全屏、列表折叠、同步滚动、配色、最后保存时间和当前标签页刷新恢复。手动锁定、空闲超时或重启工具箱后需重新验证，共享访客无法访问。
