# 仓鼠工具箱 v0.2.8

[文档目录](../README.md) · [版本变更](../../CHANGELOG.md)

新增桌面界面、计划任务和媒体预览操作。下载请前往 [Releases](https://github.com/sizhaiwu/hamster-toolbox/releases)。

## 主要变化

- **内置桌面端**：Windows 完整安装包和便携包内置独立桌面界面，默认桌面启动，仍可切换浏览器；关闭可选择托盘、退出或取消，托盘可打开资源管理器、笔记、计划任务和设置。保留未保存内容确认，后台服务停止后桌面端仍能退出。
- **计划任务**：脚本、GET / POST、常用周期与 Cron；提供四个默认暂停的示例、参数化脚本库、批量操作、工具箱及宝塔基础 JSON 导入导出、执行时间预览和独立日志。运行与记录可分页，并发、排队和日志保留可配置。远程管理员也能管理，普通共享访客不能访问。
- **mpv 播放器**：统一紧凑控制栏、竖向音量滑条和独立窗口；Ctrl+1 / Ctrl+2 设置 AB 重复，Ctrl+3 取消。视频结束后可停留、循环或关闭当前窗口，设置记忆并对新窗口生效，AB 优先。
- **资源预览**：电脑图片／视频的顶部工具栏移入显示，图片底部缩略图与文件列表悬浮；视频缩略图保留在底部，兼容播放与全片进度放进选项浮层。图片支持旋转、平滑缩放、连续拼接及左右张数记忆。
- **手机体验**：单行标题栏与紧凑的“更多”操作面板，展开不挤压画面；针对 iPhone Chrome 普通网页处理顶部安全区留白，Safari、主屏幕和全屏保留各自安全区。
- **默认观看方式**：图片／视频可分别设置默认方式；桌面端默认仓鼠独立窗口，网页与手机默认当前页。“自动选择”已移除；右键打开方式集中到子菜单，临时选择不改默认设置。

## 下载与更新

| 文件 | 用途 |
| --- | --- |
| `*-setup.exe` | 普通 Windows 用户安装或升级，推荐使用 |
| 完整 `.7z`（如提供也可用完整 ZIP） | 完整解压后便携使用，包含桌面和媒体组件 |
| `*-update.zip` | 更新程序、桌面运行时和说明，不包含 `tools`；需已有匹配组件 |

完整包包含 `desktop-runtime`，无需用户另选桌面组件或联网下载。更新前完成任务、保存编辑和笔记，导出完整加密笔记备份，再正常退出旧服务及 mpv。安装版优先用新安装器；便携包解压到新目录，更新后核对程序版本。

用户数据继续保存在原数据目录，默认 Windows 为 `%APPDATA%\hamster-toolbox`；指定 `-data` 时沿用该目录。程序更新不覆盖笔记、附件、设置、计划任务及记录。具体文件与迁移见[安装说明](../installation.md)和[计划任务](../schedules.md)。

## 使用要求

完整安装包与便携包适用于 Windows x64。Linux/macOS 请从源码构建并准备本机组件，见[平台说明](../platforms.md)。硬件编码、解码和浏览器播放取决于设备、驱动及媒体格式。
