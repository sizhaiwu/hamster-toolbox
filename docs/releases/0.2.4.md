# 仓鼠工具箱 v0.2.4 发布说明

[文档目录](../README.md) · [版本变更](../../CHANGELOG.md)

本版增加完整远程工作台，统一共享设置，并改善手机笔记和媒体播放。下载 [v0.2.4 正式发行包](https://github.com/sizhaiwu/hamster-toolbox/releases/tag/v0.2.4)，其他版本见 [Releases 列表](https://github.com/sizhaiwu/hamster-toolbox/releases)。

## 主要变化

- **完整远程工作台**：手机、平板和其他电脑可通过独立管理员口令使用工具箱、资源管理器及私密笔记。管理员权限与普通目录共享分开；笔记仍需主密码和已启用的动态码，不复用其他设备的解锁状态。
- **公共共享设置**：在工具箱、资源管理器或笔记打开“通用设置 → 共享与远程”，统一配置目录、端口、访客口令、管理员口令和远程地址。原有共享配置继续使用。
- **手机笔记**：按钮自动换行，展开列表不自动聚焦搜索；保留整页滚动，输入时适应键盘可见高度并保持编辑位置可见。密码框使用视觉遮挡，减少浏览器误提示保存密码。
- **手机资源浏览**：网格适应窄屏，改善输入字号和触摸操作；修复共享首次登录初始化错误。会话过期后明确提示重新登录，管理员保持独立登录入口。
- **悬浮视频声音**：优先有声播放，遵循默认静音选项；被浏览器拦截时静音回退，并显示当前窗口的“开启声音”按钮。
- **mpv 初始尺寸**：本机可选紧凑（800×600）、中等（1100×825）或较大，按媒体比例适配并记住选择；不重设已经打开的窗口。
- **远程播放边界**：远程页面统一使用浏览器预览，不会因手机操作在服务端电脑启动 mpv、系统打开方式或文件管理器。退出远程入口移到导航或顶部菜单，取消遮挡内容的底栏。

[远程工作台开启方法](../remote-workspace.md) · [私密笔记](../private-notes.md) · [播放说明](../media-preview.md)。

## 下载与升级

普通 Windows 用户使用 `*-setup.exe`；便携用户选择完整 ZIP。`*-update.zip` 只适用于已有匹配组件的完整目录，不包含媒体组件。

1. 等待任务结束，保存笔记，并导出包含附件的完整加密备份。
2. 退出旧工具箱及使用随包组件的播放器；备份实际数据目录，默认是 `%APPDATA%\hamster-toolbox`，自定义 `-data` 以实际路径为准。
3. 安装新版，或把完整便携包解压到新目录。程序目录与数据目录分开；不要覆盖、合并或删除两份不同的笔记库。
4. 启动后核对版本、笔记附件和共享设置；手机页面重新加载。已经运行的任务不会在重启后自动接续。

本版沿用 v0.2.3 的组件清单。升级和早期数据目录说明见 [安装与更新](../installation.md)。

## 使用边界

- 完整远程工作台默认关闭，默认要求 HTTPS；可信内网或加密组网的 HTTP 必须明确开启。普通 HTTP 不保护传输中的口令、笔记和文件。
- 管理员可访问服务端账户有权限访问的资源，不受访客共享目录范围限制；仅向自己或完全信任的人提供管理员口令。只转发共享端口，不开放本机管理端口。
- 笔记主密码无法重置，动态码不是独立的离线加密因素；单篇 Markdown 导出及附件下载是明文。
- 完整分发与安装包面向 Windows x64。Linux/macOS 可从源码构建并准备对应组件，详见 [平台说明](../platforms.md)。
- 程序和安装器尚未签名，SHA256 用于核对传输完整性。没有独立第三方密码学安全审计。
