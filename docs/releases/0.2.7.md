# 仓鼠工具箱 v0.2.7 发布说明

[文档目录](../README.md) · [版本变更](../../CHANGELOG.md)

本版增加多文件代码编辑器和资源管理器内解压，改善原生媒体多窗口与图片加载，并修复托盘后台退出、输出路径和特殊 ZIP 兼容问题。下载见 [v0.2.7 发布页](https://github.com/sizhaiwu/hamster-toolbox/releases/tag/v0.2.7)。

## 主要变化

- **直接编辑文件**：资源管理器支持新建文本文件、目录树和多文件标签；离线代码高亮、Tab 缩进、查找替换、代码提示、深浅主题与全部保存。编辑窗口可拖动、缩放和最小化，切换文件保留草稿及撤销记录，大文件输入减少全文复制。
- **编辑备份集中管理**：修改前备份保存到工具箱数据目录的 `editor-backups`，每个文件保留最近 20 个版本，资源目录不再随保存堆积备份文件夹。保留冲突校验和失败恢复；已有旧备份不自动删除。普通文件备份仍是原始文件内容，不使用私密笔记加密。
- **资源管理器内解压**：压缩包右键直接打开解压窗口，支持密码与常用密码、输出目录、扫描预览、进度、日志及停止任务，无需切换工具页面。默认保留原包并自动改名，沿用任务历史和提醒，分卷请选择首卷。
- **原生媒体多窗口**：图片预览可直接切换 mpv，图片支持滚轮缩放与复位；图片和视频分别记忆窗口大小。错开排列保持尺寸，平铺会调整尺寸；可统一暂停、静音，或单独调节每个视频的进度与音量。
- **图片和代码预览更清楚**：图片操作集中到顶部，减少首次显示闪动；网页原图使用有界内存缓存及单张预读，关闭或切换释放请求。文本预览提供高亮、行号、换行和复制。TypeScript 源文件不再误触发 TS 视频预览。
- **稳定性与兼容修复**：修复 Windows 托盘原生指针生命周期问题；目录大小按需计算；相对输出目录以输入目录为基准；兼容带较大前置数据的单卷 ZIP；打包文件夹和文件可以分别设置起始编号。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `*-setup.exe` | 推荐普通 Windows 用户安装或升级 |
| 完整 ZIP | 便携使用，解压到新目录后启动 |
| `*-update.zip` | 仅更新程序和说明，需已有匹配组件的完整目录 |

本版沿用 v0.2.6 的组件清单，每份附件附带 SHA256。更新前完成任务、保存编辑器草稿和笔记，导出完整加密笔记备份，再从托盘完全退出旧版。更新后核对“关于与更新”显示 `0.2.7`；仅刷新网页不会替换仍在运行的旧服务。

默认数据目录为 `%APPDATA%\hamster-toolbox`，使用 `-data` 时以实际路径为准。更新程序不覆盖设置、笔记和任务历史。旧版 `.toolbox-replaced-*` 可能包含需要恢复的文件，请核对后自行处理；本版不自动搬迁或删除这些备份。编辑器未保存的草稿只在当前页面内存中，刷新或退出前请保存。
