# 仓鼠工具箱 v0.2.2 发布说明

[文档目录](../README.md) · [版本变更](../../CHANGELOG.md) · [发布检查](../release-readiness.md)

本版以当前完整工具箱、资源管理器和共享能力为基线。Windows x64 正式安装包、完整便携 ZIP 和更新 ZIP 的版本均为 `0.2.2`，附件与 SHA256 见 [v0.2.2 发布页](https://github.com/sizhaiwu/hamster-toolbox/releases/tag/v0.2.2)。

## 下载选择

| 文件 | 适合谁 | 使用方式 |
| --- | --- | --- |
| `*-setup.exe` | 普通 Windows 用户，推荐 | 安装后从桌面或开始菜单打开；可选登录自启 |
| 完整版 `.zip` | 便携使用或放到固定工具目录 | 完整解压，保持程序和 `tools` 在一起，运行 `hamster-toolbox-desktop.exe` |
| `*-update.zip` | 已有匹配组件的完整版用户 | 退出旧服务后覆盖程序和说明文件；不包含 `tools`，不能单独运行 |
| `.sha256` | 需要核对传输是否完整 | 对照相应文件的 SHA256 |

本版完整分发面向 Windows 10/11 x64，内置 FFmpeg/FFprobe、ImageMagick、ExifTool、7-Zip、中文字体和 mpv，无需安装 Go、Python 或 Node.js。文件去重为 Video Duplicate Finder 的外部入口，需另行下载。Linux/macOS 需从源码构建并准备本机组件，见[平台支持](../platforms.md)。

## 本版主要变化

### 安装、启动与更新

- 提供完整安装包，支持桌面/开始菜单快捷方式、系统卸载入口和无控制台托盘启动；便携方式仍保留。
- Windows 登录自启可在安装时或“通用设置 → 启动”启用，默认关闭。自启静默进入托盘；卸载只清理指向该安装目录的自启项。
- 工具箱和本机资源管理器页面底部“关于与更新”显示当前版本、构建时间和最新正式版；开发版会单独标注，不提示降级。发布按钮始终打开 Releases 版本列表。检查失败会提示，不自动下载或安装。

### 资源管理器与观看

- 本机磁盘浏览、多标签及拖动排序、快速访问、自然数字排序、正倒序、分页与图标大小/间距记忆；返回目录恢复浏览位置。
- 单击选择、双击打开、右键菜单和属性；目录大小按需计算。本机可打开系统文件管理器或选择其他软件打开文件。
- 文件/文件夹上传与分段续传，复制、剪切、顶部粘贴和跨盘移动。同名目标可保留两份，或合并并跳过/替换；替换前保留原文件备份。
- 图片缩放、跨页连续预览、底部缩略图和侧栏视频时长；大目录先显示文件，按可见区域读取媒体信息。
- 浏览器悬停短片、多窗口悬浮图片/视频，以及 mpv 浏览器外独立查看、进度与音量控制和硬解状态。普通播放优先原画质，不兼容时提供按需兼容播放。

### 共享、设置与任务

- 可保存多个共享目录或磁盘根目录，逐目录选择只读/可修改；保存开启后随服务恢复。支持已有加密组网和 HTTPS 穿透配置，电脑、手机和平板均可用浏览器访问。
- 修复共享首次输入正确口令后仍停在登录页的问题；登录页所需静态资源在认证前可加载，目录、文件与管理接口权限保持生效。
- 通用设置提供播放、字号、标签恢复、任务弹窗/声音和磁盘缩略图缓存；缓存默认上限 256 MB，可关闭或清理。
- 批处理预览与日志可全屏查看。图片/视频压缩、清理元数据和视频缩略图支持并发、任务历史及失败/未完成项重新预览；不会续接单个文件内部编码状态。

### 整理与媒体处理

- 保留目录统计命名、普通/按示例/正则重命名、自定义目录编号与续号、媒体信息命名、PDF 图册索引等能力，并完善文件变化复核和冲突保护。
- 图片压缩按格式筛选，支持 JPEG、PNG 和静态 WebP。PNG 可无损优化，或转高质量 WebP；保留 `.png` 文件名时内部仍是 WebP，需考虑其他软件兼容。
- 视频提供 H.264/H.265、硬件优先和 CPU 模式、画质与阈值设置、编码回退和结果校验。完善 HDR 选择、旧 FFmpeg 参数兼容，以及复制音轨时间戳异常时的 AAC 重试和衔接补偿。
- 视频缩略图按时间均匀生成拼图；快速定位无画面时自动兼容重试，保留目标时间，不复用旧帧冒充成功，兼容错误后缀的 MPEG-TS。
- 7-Zip 打包支持分卷、加密、附加文件、编号与校验；解压支持常见分卷及仅剩 `.001/.002` 的字节分卷。任务状态分别显示总包数和当前包的解压/检查/写出阶段，无法计算时显示进行中。
- 11 项批处理共用 GUI/CLI 逻辑；CLI 默认预览，显式 `--execute` 才执行。页面可复制 CLI，部分工具可导出底层命令。参数、示例和限制见 [CLI 手册](../cli-reference.md)。

## 从旧版或测试版升级

1. 等待批处理结束，从托盘退出旧工具箱；控制台启动时关闭控制台，并正常关闭正在使用组件的 mpv 等程序。更新不会自动接续运行中的任务。
2. 可备份当前用户数据目录，Windows 默认 `%APPDATA%\media-toolbox`，自定义 `-data` 时以实际路径为准。备份含私人配置、共享设置、历史和账户加密的密码库，不要公开分发。
3. **从 v0.2.1 或更早版本升级，优先用本版安装包或完整 ZIP。** 本版组件有变化，单独更新程序不能替换旧 `tools`。便携完整包解压到新目录，不要混用新旧 DLL。
4. 安装过测试版时，退出旧进程后运行正式安装包；便携测试版则使用正式完整目录。保留同一用户数据目录即可读取已有设置；常用密码绑定 Windows 账户，换电脑或换账户需要重新添加。
5. 启动后在“关于与更新”核对版本，在组件区检查路径。共享的端口、权限及网络转发需再次确认；有失败/中断记录时重新预览，再决定执行。

程序和组件更新不覆盖用户资源；卸载保留个人配置和任务历史。升级与回退的详细说明见[安装](../installation.md)和[打包](../packaging.md)。

## 使用边界

- 媒体处理输出副本；改名会直接修改原名称。清理非媒体文件、解压后清理原包默认关闭，删除默认尝试主机回收站，失败时保留，不自动永久删除。
- 预览、硬件编码与硬解取决于格式、显卡、驱动和浏览器。不能保证所有媒体均可直接播放、压缩后一定变小或完全无可见损失；重要资源应保留备份。
- 共享默认关闭，新目录默认只读，使用统一口令和目录权限；适合可信个人设备，不提供逐用户授权、磁盘配额或完整审计。公网浏览器访问需要 HTTPS，不对外开放本机管理入口。
- 当前程序和安装器未签名。SHA256 用于核对文件完整性，不代替发布者身份认证。macOS、其他 Windows 账户与不同硬件的验收边界见[发布检查](../release-readiness.md)。
