# 仓鼠工具箱 v0.2.6 发布说明

[文档目录](../README.md) · [版本变更](../../CHANGELOG.md)

本版改进多任务操作和提醒，增加压缩密码记忆，并修复笔记附件看图与视频缩略图问题。下载见 [v0.2.6 发布页](https://github.com/sizhaiwu/hamster-toolbox/releases/tag/v0.2.6)。

## 主要变化

- **不同工具同时运行**：各自保留预览、日志、进度与取消操作；侧栏显示运行状态和数量。同一工具同时一个任务，修改同一资源或输出路径重叠时仍有冲突保护，硬件资源由任务共享。
- **提醒与状态更清楚**：完成结果在每个已打开页面独立排队；关闭提醒或进入工具页面后隐藏结束状态，新窗口不再重放旧提醒。运行进度与可执行的待执行状态保留，日志和历史不清除。
- **任务历史同步并行任务**：后台工具的开始、进度和完成能在历史窗口更新；载入参数、重扫按目标工具判断忙碌状态，操作前再次检查，清理时保留活动记录。
- **压缩视频保留原格式**：默认保留原名称和支持的 MP4/MOV/M4V/QT/MKV/TS 封装，也可统一输出 MP4。保留音频、显卡/CPU 与封装兼容回退；不支持的格式在扫描时提示，10-bit/HDR 不自动降为 8-bit SDR。体积与原码率筛选增加单独说明，空扫描结果会提示检查条件。
- **打包和解压记住密码**：Windows 默认开启本机加密记忆，分别恢复最近输入或选择的常用密码。可关闭并清除对应记忆，列表保留；保存失败有提示，普通设置、浏览器存储与任务历史不保存明文密码。
- **笔记附件独立看图**：底部“查看图片”打开看图窗口，支持缩放、拖动、适应窗口与手机按钮操作；正文没有引用或图片已缓存也能查看。关闭、切换笔记或锁定后清理窗口资源。
- **缩略图避开临时帧占用**：单帧通过内存管道读取，消除反复删除 `frame.png` 的失败点；保留兼容定位和取消，验证 Windows 锁文件、MP4/MKV 并发与错误后缀的 TS 视频。
- **中文路径自检**：修复 ExifTool 自检素材在中文临时目录下读取失败的问题，支持中文配置与临时路径。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `*-setup.exe` | 推荐普通 Windows 用户安装或覆盖升级 |
| 完整 ZIP | 便携使用，完整解压到新目录后启动 |
| `*-update.zip` | 仅更新程序和说明，需已有匹配组件的完整目录 |

本版沿用 v0.2.5 的组件清单，每份附件附带 SHA256。结束任务、保存笔记并导出完整加密备份，从托盘完全退出旧工具箱后更新，再核对“关于与更新”显示 `0.2.6`。仅刷新网页不会更换已运行的服务。

用户数据默认保存在 `%APPDATA%\hamster-toolbox`，自定义 `-data` 时以实际路径为准。更新程序不替换个人设置、笔记或历史。首次使用本版密码记忆，需要重新输入或选择一次；Windows 账户加密的密码文件不能当作跨账户迁移备份。
