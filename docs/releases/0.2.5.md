# 仓鼠工具箱 v0.2.5 发布说明

[文档目录](../README.md) · [版本变更](../../CHANGELOG.md)

本版修复图片元数据清理失败的问题，并增加处理预览与运行日志的收起按钮。下载 [v0.2.5 正式发行包](https://github.com/sizhaiwu/hamster-toolbox/releases/tag/v0.2.5)，其他版本见 [Releases 列表](https://github.com/sizhaiwu/hamster-toolbox/releases)。

## 主要变化

- **图片错后缀兼容**：PNG、WebP 等图片即使使用了 `.jpg` 等不同后缀，也按实际格式清理临时副本。输出保留原文件名和后缀，不重新编码，原文件保留。此类文件的底层命令入口会引导使用工具箱 CLI，避免直接执行不完整的 ExifTool 命令。
- **中文路径兼容**：ExifTool 清理改用 UTF-8 参数文件，避免 Windows 命令行文件名编码警告和路径转换问题。
- **预览与日志收起**：两个栏目可分别收起和展开，当前浏览器记住各自状态。收起后后台任务、预览和日志继续更新；全屏查看后恢复原状态。

## 下载与升级

| 文件 | 适合谁 |
| --- | --- |
| `*-setup.exe` | 普通 Windows 用户，安装或覆盖升级 |
| 完整 ZIP | 便携使用，解压到新目录后启动 |
| `*-update.zip` | 已有匹配组件的便携目录，仅更新程序和说明 |

本版沿用 v0.2.4 的组件清单；每个附件附带 SHA256。更新前等待任务完成，保存笔记并备份数据，从托盘退出或关闭控制台，再更新程序。数据默认保存在 `%APPDATA%\hamster-toolbox`，自定义 `-data` 时以实际路径为准。

更新后重新启动工具箱，核对“关于与更新”显示 `0.2.5`；仅刷新网页不会更新已运行的后台进程。开发目录与安装目录是不同的程序入口，更新其中一处不会替换另一处。
