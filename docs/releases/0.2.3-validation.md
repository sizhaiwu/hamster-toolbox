## 已知边界

- 本轮安装验收使用当前 Windows 测试机与独立配置目录，相同载荷的安装器隔离了系统集成标识；最终公开安装标识在另一台实体电脑上尚未复验。
- 完整分发与安装器只面向 Windows x64；macOS 缺少真机验证，ARM64 主要为编译验证。Linux/macOS 的媒体组件、桌面播放器和回收站仍需对应环境验收。
- 常用压缩密码列表绑定 Windows 账户；私密笔记使用主密码与独立备份，两者不是同一种密码库。
- Video Duplicate Finder 仍为需要另行安装的外部入口。
- 动态码是应用层验证，不能替代强主密码；当前没有独立第三方密码学安全审计。浏览器刷新恢复保留临时会话凭证，离开电脑前仍需手动锁定。
- 程序和安装器未签名，SHA256 只验证传输完整性。驱动、硬编解码和浏览器媒体支持受实际设备影响。
- 源码/UI 测试不代表最终安装、所有媒体格式或所有网络方案均已验证；不能宣称没有风险或绝对安全。
