# 便携版、安装版与系统托盘

[文档目录](README.md) · [打包说明](packaging.md)

## 使用方式

Windows x64 保留完整便携 ZIP，同时提供安装包 `*-setup.exe`。安装向导可选择目录、创建桌面与开始菜单快捷方式，并提供系统卸载入口。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\HamsterToolbox`，不要求管理员权限。开机自启可选，默认关闭；不添加系统服务或防火墙规则。

快捷方式启动 `hamster-toolbox-desktop.exe`：没有控制台窗口，仍在默认浏览器中操作。便携目录也能使用这个文件，或运行 `hamster-toolbox.exe -tray`。CLI 和终端排错继续使用 `hamster-toolbox.exe` / `start-toolbox.cmd`。

单击通知区域的仓鼠图标打开工具箱；右键可打开工具箱、资源管理器或退出。图标可能位于隐藏图标区域。关闭浏览器后，服务和共享继续运行；退出应使用托盘菜单。批处理执行或扫描期间，退出不可用，请先回到页面完成或取消。退出会停止共享、上传和网页播放。

同一数据目录的托盘版重复启动会打开已有实例，不重复启动服务。普通控制台模式保留原行为，请勿同时让多个实例使用同一份设置和资源；需要独立实例时用 `-data` 指定其他目录。Linux/macOS 仍使用普通服务模式，本轮托盘与安装包仅适用于 Windows。

## 开机自启

安装时勾选“登录 Windows 后自动在系统托盘运行”，或者打开工具箱/本机资源管理器的 **通用设置 → 启动**，开启“开机自启”。登录后静默启动托盘和已保存的共享，不主动打开浏览器；点击托盘图标即可进入。关闭开关只影响以后的登录，不会结束当前任务。

仅作用于当前 Windows 用户，无需管理员权限。设置读取系统中的自启项；如果另一份工具箱已配置自启，开启将切换到当前这份程序。便携版也能开启，但应先把完整目录放到固定位置，移动后需重新设置。使用自定义 `-data` 的实例会保留该数据目录。

自启使用 [Windows 当前用户 Run 项](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)，命令为托盘启动文件加 `-tray -no-open`。Windows 可能延迟启动；如果在系统“启动应用”中禁用了它，还需在系统中重新启用。Linux/macOS 暂不提供此开关。

## 更新与卸载

工具箱页面底部的 **关于与更新** 与版本号合并显示，旁边提供 GitHub 仓库链接；本机资源管理器也在页面底部提供这两个入口。点击可查看最新正式版、构建时间和打开 GitHub 发布页。开发构建会标注“开发版”，不会把较旧的正式版提示成升级。打开本机页面后会后台查询公开发布信息，正常结果缓存一小时，手动检查最短间隔 30 秒；离线、限流或网络失败时会明确显示检查失败，不会误报“已是最新”。检查不上传目录、配置、密码或日志，不自动下载或安装。共享访客不显示此入口，也不能调用主机版本检查接口。

“打开发布页”始终进入仓库的 Releases 版本列表，方便查看最新版本或选择其他版本，不固定到某个标签。

更新前结束任务并从托盘退出。安装器发现新版程序仍在运行时，会要求先退出，不强制终止任务；旧版不一定提供运行标记，仍应手动确认。mpv 使用组件时也应先正常关闭。

卸载移除安装文件、快捷方式和指向该安装目录的自启项，保留用户配置目录中的设置、密码库、任务历史及资源文件。另一份程序目录的自启项会保留。安装版沿用原数据目录，首次启动可能读取便携版已保存的共享设置。

## 维护者构建

准备 Go、Node/npm/jsdom 和 [Inno Setup 官方编译器](https://jrsoftware.org/inno-setup/downloads)（6.5+ 或 7）后，双击 `package-installer.cmd`，或运行：

```powershell
.\package.ps1 -Installer
.\package.ps1 -Installer -ISCC 'D:\build-tools\Inno Setup\ISCC.exe'
```

普通 `package.cmd` 继续只生成便携 ZIP 和更新 ZIP，无需 Inno Setup。安装包使用同一份已校验组件和白名单文件，另生成安装 EXE 及 SHA256 文件；脚本不会上传或发布。

安装器和启动文件目前未签名；最终发行前仍需检查真实安装、升级、卸载及不同 Windows 账户。开发验收包不作为正式发布。
