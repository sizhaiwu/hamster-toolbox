# 便携版、安装版与系统托盘

[文档目录](README.md) · [打包说明](packaging.md)

## 使用方式

Windows x64 保留完整便携 7z（也可提供 ZIP），同时提供安装包 `*-setup.exe`。安装向导可选择目录、创建桌面与开始菜单快捷方式，并提供系统卸载入口。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\HamsterToolbox`，不要求管理员权限。开机自启可选，默认关闭；不添加系统服务或防火墙规则。

快捷方式启动 `hamster-toolbox-desktop.exe`：没有控制台窗口，完整包默认使用独立桌面窗口，也可切换浏览器。便携目录也能使用这个文件，或运行 `hamster-toolbox.exe -tray`。CLI 和终端排错继续使用 `hamster-toolbox.exe` / `start-toolbox.cmd`。

## 桌面窗口与浏览器

Windows x64 的完整安装包和完整便携包均内置桌面界面，安装或解压后直接使用，无需另选组件或联网下载。默认在独立桌面窗口打开；在 **通用设置 → 启动 → 桌面界面** 可切换默认浏览器，或临时打开另一种界面。目录不完整时会回退浏览器并提示使用完整包。

两种界面共用 Go 服务、原有笔记和设置。点击桌面窗口关闭按钮时可选择转入托盘、退出工具箱或取消，并可记住选择。转入托盘会保留后台任务、计划任务和共享；退出会检查运行任务与未保存内容。桌面窗口大小与会话保存在原数据目录的 `desktop-profile/`，升级不会删除；浏览器独有的显示偏好可能需要重新选择，私人笔记正常解锁即可。

桌面运行时位于程序目录的 `desktop-runtime/`。卸载清理程序文件，保留原数据目录和私人笔记。Linux/macOS 继续使用浏览器服务模式。

单击通知区域的仓鼠图标恢复界面；右键可打开工具箱、在浏览器中打开、资源管理器、私密笔记、计划任务、通用设置或退出。菜单中的“在浏览器中打开”使用系统默认浏览器，不改变已保存的默认启动方式；其他入口沿用当前启动方式。打开设置会直接显示设置弹窗，其他已打开页面和未保存编辑保留。安装版托盘与普通 EXE 退出到托盘后的菜单保持一致。图标可能位于隐藏图标区域。关闭浏览器后，服务和共享继续运行；退出应使用托盘菜单。批处理执行或扫描期间，退出不可用，请先回到页面完成或取消。退出会停止共享、上传和网页播放。

同一数据目录的托盘版重复启动会打开已有实例，不重复启动服务。普通控制台模式保留原行为，请勿同时让多个实例使用同一份设置和资源；需要独立实例时用 `-data` 指定其他目录。Linux/macOS 使用浏览器服务模式，托盘与安装包仅适用于 Windows。

## 开机自启

安装时勾选“登录 Windows 后自动在系统托盘运行”，或者打开工具箱/本机资源管理器的 **通用设置 → 启动**，开启“开机自启”。登录后静默启动托盘和已保存的共享，不主动打开浏览器；点击托盘图标即可进入。关闭开关只影响以后的登录，不会结束当前任务。

仅作用于当前 Windows 用户，无需管理员权限。设置读取系统中的自启项；如果另一份工具箱已配置自启，开启将切换到当前这份程序。便携版也能开启，但应先把完整目录放到固定位置，移动后需重新设置。使用自定义 `-data` 的实例会保留该数据目录。

自启使用 [Windows 当前用户 Run 项](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)，命令为托盘启动文件加 `-tray -no-open`。Windows 可能延迟启动；如果在系统“启动应用”中禁用了它，还需在系统中重新启用。Linux/macOS 暂不提供此开关。

## 更新与卸载

工具箱页面底部的 **关于与更新** 与版本号合并显示，旁边提供 GitHub 仓库链接；本机资源管理器也在页面底部提供这两个入口。点击可查看最新正式版、构建时间和打开 GitHub 发布页。开发构建会标注“开发版”，不会把较旧的正式版提示成升级。打开本机页面后会后台查询公开发布信息，正常结果缓存一小时，手动检查最短间隔 30 秒；离线、限流或网络失败时会明确显示检查失败，不会误报“已是最新”。检查不上传目录、配置、密码或日志，不自动下载或安装。共享访客不显示此入口，也不能调用主机版本检查接口。

“打开发布页”始终进入仓库的 Releases 版本列表，方便查看最新版本或选择其他版本，不固定到某个标签。

更新前结束任务并从托盘退出。安装器发现新版程序仍在运行时，会要求先退出，不强制终止任务；旧版不一定提供运行标记，仍应手动确认。mpv 使用组件时也应先正常关闭。

卸载移除安装文件、快捷方式和指向该安装目录的自启项，保留用户配置目录中的设置、常用压缩密码列表及最近密码记忆、私密笔记和任务历史，不删除用户资源。另一份程序目录的自启项会保留。安装版沿用原数据目录，首次启动可能读取便携版已保存的共享设置。

### 笔记与早期测试数据

升级前先保存笔记，并在“安全与备份”导出包含图片和文件的完整加密备份。正常替换程序不会覆盖用户数据；重新启动需要首次解锁，之后可按设置恢复刷新会话。单篇 Markdown 导出是明文，不能代替完整备份；有附件时不能只复制 `vault.json`。

当前 Windows 默认数据目录是 `%APPDATA%\hamster-toolbox`。早期测试版若使用 `%APPDATA%\media-toolbox`，新版不会自动搬迁：退出所有相关实例后，完整复制到新的数据目录，或继续用 `-data` 指定原目录。不要把两份不同的数据目录直接合并；升级后找不到设置时应先确认启动所用目录。换电脑迁移笔记请用完整加密备份，Windows 账户加密的常用压缩密码列表仍需重新添加。

旧程序不一定能读取新版笔记格式。回退前退出新程序，使用升级前保存的数据备份。[v0.2.3 升级说明](releases/0.2.3.md)。

## 桌面操作

程序与安装器未签名，请从仓库 Releases 下载；附件旁的 SHA256 可用于核对文件完整性。

桌面端支持 F5 / Ctrl+R 刷新、F11 全屏、Ctrl+F 查找当前页面、Ctrl++ / Ctrl+- 调整界面缩放、Ctrl+0 恢复默认，F1 查看快捷键。文件编辑器打开时 Ctrl+F 使用编辑器自己的搜索。笔记及文件编辑未保存时会确认后再关闭或刷新，包括新开的子窗口。从托盘打开其他入口时保留现有编辑窗口；任务与下载的汇总进度显示在任务栏，失败时可查看对应日志。窗口记住位置、大小和所在屏幕，屏幕断开后会调整到可见范围。

点击桌面窗口右上角关闭按钮，可以选择“退出到系统托盘”“退出工具箱”或“取消”。退出到托盘会隐藏窗口并保留正在编辑的内容；从托盘点击仓鼠图标即可恢复。普通控制台 EXE 启动也支持此操作，会按需创建桌面托盘图标；已有后台托盘时不重复创建。彻底退出会先检查批处理、计划任务与文件操作，并对未保存的编辑进行确认。选择退出到托盘时会分离普通控制台，让后台继续运行；需要彻底关闭时使用托盘的退出菜单。

**通用设置 → 启动 → 桌面窗口** 可以设置关闭方式、75%～200% 界面缩放、启动时恢复工作区、后台系统通知和后台节省资源。关闭询问中也能勾选“记住选择”。这些桌面设置保存在当前工具箱数据目录的 `desktop-profile/desktop-settings.json`，不会修改其他用户的设置。

工作区恢复默认开启，保存已打开页面、资源管理器目录标签、编辑文件路径和窗口位置到 `desktop-profile/workspace.json`。不会保存笔记正文、文件编辑内容、密码或访问口令；重新打开编辑文件时读取磁盘最新内容，笔记遵循原有解锁规则。退出前仍需保存编辑内容。关闭工作区恢复会清除已保存的位置记录。工作区中的目录与文件路径是本机明文设置，迁移和分享日志时请留意。

可以从系统文件管理器拖入目录到工具的输入目录；拖入文件会填写其所在目录，需先扫描预览核对处理范围。拖入“打包资源”的附加文件框可追加多个文件。向本机资源管理器列表拖入文件或文件夹时，会先询问复制或移动（按住 Shift 拖入预选移动），沿用同名冲突提示和跨盘校验流程。远程浏览器继续使用上传，不会操作访问设备的本机路径。

窗口未在前台时，普通工具任务完成会发送系统通知，多个窗口不会重复发送同一条；点击可进入对应工具。可关闭系统通知，声音遵循通用设置的提示音开关，Windows 勿扰模式也可能隐藏通知。计划任务仍使用任务内日志查看结果。窗口隐藏或最小化后会降低界面状态轮询频率，停止悬停预览和图片预读，后台任务、正在观看的视频和笔记自动锁定继续正常运行。

以控制台方式启动时，关闭命令行窗口会停止后台服务。桌面窗口仍可正常退出；选择转入托盘时会提示服务已停止，可关闭桌面端或保留窗口，未保存内容仍会确认。需要继续使用时请重新启动工具箱。
