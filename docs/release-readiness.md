# v0.2.2 发布验收

[文档目录](README.md) · [版本说明](releases/0.2.2.md) · [打包说明](packaging.md)

本版的 Windows x64 分发包括完整安装包、完整便携 ZIP、程序更新 ZIP 及各自 SHA256。附件版本为 `0.2.2`，从包含最终修复的源码重新构建，未沿用旧开发安装包。

## 已完成的检查

- Go 测试、`go vet`、Go 格式和 31 组界面回归通过；打包安全检查覆盖白名单、组件哈希、目录越界、链接、重复目标与临时目录重命名边界。
- 最终 ZIP 的全部 CRC、SHA256、目录项和版本信息通过检查；更新 ZIP 不含组件，完整包包含两种启动程序与所需工具。
- 从最终完整 ZIP 解包，在中文含空格目录、空配置和仅系统 PATH 下验证组件来源与十一项批处理自测；mpv 使用合成视频验证无窗口解码。
- 与最终包相同的载荷完成隔离安装、安装后程序/组件哈希核对、GUI 启动、同数据目录重复启动、静态资源读取和卸载。安装标识及注册表键隔离，不替换用户现有安装或共享设置。
- 自启验收覆盖默认关闭、明确启用、升级保留自定义数据目录、关闭、卸载清理与保留其他安装目录的自启项；未改写真实 Run 配置。
- 共享首次登录、权限与静态资源隔离、分卷解压与进度、异常音轨时间戳和缩略图定位均有回归。缩略图另使用合成 MPEG-TS 与本机明确选择的只读样本验证，原文件哈希不变；样本和私人路径不分发。
- 待提交内容和发行文件排除个人配置、密码库、会话、日志、缓存及临时验收目录；历史与本版提交身份均使用仓库公开身份。文档图片仅使用合成素材。

源码的 Windows、Linux、macOS（Intel）自动检查以 [GitHub Actions](https://github.com/sizhaiwu/hamster-toolbox/actions) 的实际运行结果为准。macOS 的 Intel 与 Apple Silicon 程序及测试代码另通过交叉编译；不能把交叉编译或自动检查等同于所有平台桌面功能的真机验收。

## 验证范围与使用边界

- 本次最终包验收在当前 Windows 测试机与独立配置目录完成，另一台实体电脑尚未复验。已有测试版的安装反馈可供参考，但不替代最终包检查。
- 完整分发面向 Windows 10/11 x64。Linux/macOS 需源码构建并安装本机依赖；没有 macOS 桌面真机验收。Video Duplicate Finder 为外部入口，需另行安装。
- 显卡编码、硬解、浏览器播放、压缩率和画质取决于设备与媒体，不承诺所有组合都可用。测试入口见[测试指南](testing.md)，格式与策略见[视频压缩](video-compression.md)。
- 程序与安装器未签名。SHA256 用于核对传输完整性，不代替发布者身份认证。
- 改名没有全局撤销；文件移动或合并失败可能保留已完成项。媒体处理默认输出副本，清理选项默认关闭；重要资源应另有备份。
- 共享默认关闭，新目录默认只读，采用统一口令与目录权限，面向可信个人设备，不提供逐用户授权、配额或完整审计。
- 个人数据与程序目录分开，卸载保留设置；常用密码绑定 Windows 账户，换电脑或账户需重新添加。中断后的四类媒体任务可重扫未完成文件，单个文件从头处理。
