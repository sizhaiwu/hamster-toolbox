# 完整远程工作台

[文档目录](README.md) · [文件共享](file-browser.md) · [私密笔记](private-notes.md)

本功能自 v0.2.4 提供，旧版需升级；具体附件状态见[发布说明](releases/0.2.4.md)。

手机、平板或另一台电脑可以通过浏览器使用工具箱、资源管理器和私密笔记。使用现有共享端口，默认 `18788`，不需要对外开放本机管理端口。

[手机远程工作台截图](images/remote-workspace-mobile.jpg) · [管理员登录页](images/remote-admin-login.jpg)

## 开启与登录

1. 在运行工具箱的电脑打开“通用设置 → 共享与远程 → 配置共享与远程访问”。
2. 开启共享服务，在“完整远程工作台（管理员）”中勾选“允许远程使用完整工具箱”，设置独立的管理员口令并保存。
3. 默认要求 HTTPS；已有 HTTPS 穿透或代理可继续使用。确实使用可信内网或加密组网时，可以明确勾选“允许可信内网或加密组网使用 HTTP”。HTTP 自身不加密传输口令、笔记和文件内容。
4. 手机访问共享地址后的 `/admin/`，例如 `https://files.example.com/admin/`，输入管理员口令进入整个工具箱。设置中的“完整工具箱登录”也是这个入口。
5. 进入“私密笔记”后，再输入笔记主密码，以及已启用的验证器动态码或恢复码。可以新建、编辑、搜索、查看历史和上传/下载附件。

只需要完整工作台时，可不添加普通文件共享目录。若同时设置了普通共享目录，仍需单独设置文件共享口令。开启状态随服务启动恢复；电脑需要开机且工具箱保持运行。

## 权限范围

| 身份 | 可以使用 |
| --- | --- |
| 普通文件共享访客 | 已配置的共享目录及其读写权限 |
| 远程管理员 | 整个工具箱、服务端资源管理器和任务管理 |
| 远程管理员 + 笔记解锁 | 已解锁笔记的正文、编辑、附件、备份等笔记功能 |

管理员可以处理服务端账户有权限访问的文件，运行改名、压缩、打包、解压等任务，并使用工具箱中该账户的常用压缩密码库及任务记录。管理员口令只给自己或完全信任的人；它不受普通共享目录的范围限制。笔记仍按主密码加密保存，管理员登录不会复用电脑上的笔记解锁状态。

每个管理员浏览器有独立的登录凭据、笔记解锁状态及服务端加密草稿。电脑与手机可以分别解锁，同一篇笔记被其他设备修改后，旧版本保存会被拒绝，避免静默覆盖；需要重新打开或保留草稿后再处理。手机修改后，电脑中已打开的旧页面需要重新读取笔记。

## 使用与退出

- 页面提示“远程管理”，处理路径、依赖程序与任务结果均位于服务端电脑。手机上的文件先通过上传入口传入电脑，再选择对应目录处理。
- 刷新或关闭网页不会停止已经开始的工具任务；关闭整个工具箱服务会中断任务。浏览器上传、播放仍受连接状态影响。
- 远程页面统一使用浏览器预览，不提供 mpv、系统打开方式或启动本地文件管理器；服务端也会拦截这些请求，避免手机操作意外在电脑弹出窗口。本机页面仍可使用原生播放器。
- 保存笔记并确认“已加密保存”后，打开导航栏的“远程会话”，再点击“退出远程”；笔记页面的入口位于顶部菜单。退出会撤销本浏览器的管理员访问并锁定其笔记，不停止已开始的批处理任务，也不锁定电脑或其他手机的笔记。
- 管理员会话空闲 30 分钟或登录超过 8 小时后失效，页面会显示重新登录提示，不会误跳到普通文件共享的口令框。笔记自己的空闲锁定设置另行生效。
- 修改或关闭共享设置会撤销远程管理员会话。修改共享端口、口令或开启状态时，当前连接可能断开，需要使用新地址重新登录。

## 验证范围

自动回归覆盖默认关闭、传输要求、独立口令、Cookie 与请求校验、跨来源拦截、会话失效、退出/撤销、本机凭据隔离、文件范围读取，以及笔记动态码、跨设备编辑冲突和加密附件。浏览器测试使用合成笔记和临时配置，不启用实际用户的远程管理。

公网使用 HTTPS 并仅转发资源共享端口；已有网络连接方法见[远程访问教程](remote-access-quickstart.md)。安装器与所有手机浏览器的实机行为仍需对应环境验证。
