# 资源管理器与内网共享

[文档目录](README.md)

[返回首页](../README.md) · [安全与数据保护](safety.md)

当前资源管理器覆盖本机文件管理、媒体观看和可选共享。适配 PC、手机和平板的浏览器，电脑仍需运行工具箱；其他设备不用安装客户端。

共享设备首次输入正确口令后应直接进入文件列表，不需要刷新。页面会在登录前加载所需界面脚本，但目录、文件和管理接口仍保留认证及权限检查。浏览器阻止 Cookie 或页面初始化失败时会显示原因，服务端更新后应重新打开共享页面。

其他设备的操作界面见[共享口令页与登录后的资源浏览截图](remote-access.md#访客访问示例)，实际组网步骤见[远程访问新手教程](remote-access-quickstart.md)。

目录右键“属性”的大小行可按需点击“计算”，显示逻辑文件大小、文件数和子目录数；支持停止和关闭取消，不读取文件内容。同一服务同时只运行一个大小统计，最长约两分钟；链接、受保护/不可读项目、超深或超大目录会明确提示部分结果，不等同于磁盘实际占用。

复制/移动遇到同名目标时会弹窗选择：保留两份、合并目录并跳过同名文件、合并并替换同名文件。默认保留两份。替换前先复制并校验，原文件保存在目标旁的 `.toolbox-replaced-…` 备份目录，完成提示显示位置；目标独有文件保留，确认结果后再自行处理备份。移动时被跳过的源文件保留；失败/取消不会撤销已完成的文件。目录合并按文件处理，不提供整棵目录的原子回滚。

## 在本机浏览

桌面宽度足够时，文件操作、搜索和排序合并在同一行：保留选择、新建文件夹、上传和粘贴，选中单项后可直接打开；上传文件夹、本地打开、复制、剪切、改名等位于“更多”。右侧提供搜索、包含子目录、排序和视图切换；“显示”集中管理悬停预览、mpv 和图标大小/间距。窄屏自动换行，按钮不依赖横向滚动；手机粘贴和视图切换使用带用途标签的图标。菜单支持点击外部关闭、Esc 关闭并返回触发按钮。普通浏览说明不再固定占一行，可从“更多 → 操作提示”查看；操作结果浮出显示并自动收起，错误和进行中的处理不会按普通提示自动收起，消息可手动关闭。参见[手机操作栏示例](images/explorer-mobile.jpg)。

打开工具箱左侧导航的“资源管理器”，左侧导航底部的“返回工具箱”可回到工具页；手机先展开左侧导航。共享访问者不显示管理入口。顶部直接显示标签栏，不重复显示当前目录大标题。“此电脑”列出磁盘，也可以在地址栏粘贴具体路径。支持返回、上级目录、面包屑、当前目录搜索、按名称/大小/修改时间排序、图标与列表视图、快速访问。底部可选每页 50、100、200、500 或 1000 项，默认 200 项，自动记住选择；大图标较多或设备较慢时可选较小数量。超大目录分批读取完整项目，需要时进入更具体的子目录。

排序可选名称、修改时间或文件大小，并单独选择正序/倒序，文件夹始终在文件前面。名称中的数字按自然顺序比较，例如 `1 - 相册`、`2 - 相册`、`10 - 相册`、`1022 - 相册`。Windows 使用系统的逻辑名称比较，接近系统资源管理器；其他系统采用自然数字排序，文字和符号的细节可能随系统不同。

标签和返回/前进/上级/地址栏一起固定在列表上方；长列表向下滚动后，右下角出现“↑ 顶部”。标签左侧的按钮可向左收起或展开导航，桌面收起后释放列表宽度，手机上用于打开或关闭目录抽屉。工具箱主页也支持收起导航。按钮悬停可查看用途。图标视图中，点击“显示 → 图标大小与间距”可展开图标大小与项目间距滑块；设置会记住。列表视图的名称、大小和修改时间表头可点击排序，再次点击切换正序/倒序。行或卡片悬停时出现“···”更多操作，触屏设备始终显示该入口。

返回、前进、上级、刷新等使用统一的 SVG 图标，悬停可查看用途。资源列表和按钮文字禁止拖选，地址输入框、属性值与文本预览仍可选择复制。电脑可右键文件或目录，使用预览、打开、新标签打开、复制路径、下载、改名、移动和删除；菜单按当前选择和权限显示，多选后右键保留已选项目。目录空白处右键可新建、上传、刷新或选择本页。键盘可在项目上按 Shift+F10，菜单中方向键切换、Esc 关闭。删除仍需确认，默认进入回收站；只读共享不提供改名、移动和删除，也不能打开本机文件管理器。

列表和图标视图均为单击高亮选中、双击打开目录或预览文件；单击不会显示或勾选左上角复选框。选中一个项目后可点工具栏“打开”，键盘也可按 Enter；手机支持双击，或单击选中后点“打开”。工具栏点击“选择”后可点击项目或勾选框多选，再点“完成选择”清空选择并恢复浏览。电脑可 Ctrl/⌘ 点击逐个多选、Shift 点击连续选择、Ctrl/⌘+A 全选本页，Esc 退出选择；在输入框或预览窗口中不接管这些按键。选中后可改名、移动、删除，单个文件可以下载；只读共享仍不能修改文件。新建文件夹和上传位于工具栏。

Windows 主机支持 `.lnk` 目录快捷方式：双击进入真实目标文件夹，右键“在新标签页打开目标文件夹”或鼠标中键可另开标签；返回按钮可回到快捷方式所在目录。只在点击时读取目标，不会在列目录时遍历目标磁盘。目标失效、磁盘断开或指向程序/普通文件时显示原因，不执行快捷方式中的程序或命令。改名、移动和删除仍操作快捷方式文件本身。共享访问仅允许跳转到当前共享根目录以内，不能借快捷方式访问其他磁盘或未共享目录；Linux/macOS 主机需直接访问真实目录。

鼠标侧键“后退/前进”在资源管理器页面内控制当前目录标签的历史；部分鼠标驱动发出的 `Alt+←/→` 也按目录导航处理。打开属性或普通预览等弹窗时不切换目录。浏览器自身工具栏的返回/前进仍由浏览器控制。

右键文件、文件夹或磁盘选择“属性”，可查看名称、类型、位置、文件字节数与修改时间；图片还显示真实编码与像素分辨率，视频显示时长、分辨率、音视频编码和封装格式。Windows 还显示创建/访问时间和只读、隐藏标记，其他系统可显示权限。目录空白处菜单可查看当前目录属性。不自动遍历整个目录统计大小；共享中只显示共享内的位置，不暴露主机绝对路径。组件缺失或损坏文件的信息不可读时，基本属性仍可显示，并提示原因。

视频在图标视图显示时长角标，在列表视图显示“时长”列。只对当前可视区域及附近的视频读取信息，同时最多探测 2 个；屏幕外不会整批扫描，离开目录会取消未完成请求，已读取的信息会缓存。几百或上千视频的目录仍先显示文件列表，时长随后补齐；无法读取时显示“未知”，不影响打开原视频。列表中的“时长”暂不参与排序。

本机管理时可点击“更多 → 在本地打开”，将当前目录交给运行工具箱这台电脑的系统文件管理器：Windows 资源管理器、macOS Finder 或 Linux 默认文件管理器。需要本机有可用的桌面环境；“此电脑”尚未进入具体磁盘/目录时不能点击。此操作只打开文件夹，内网共享访问者无法调用。文件名按文字显示，不会把文件中的脚本作为工具箱页面执行。

本机文件的右键菜单提供“打开方式…”：可点击“选择系统应用”调用 Windows/macOS 的应用选择窗口，也可展开“指定程序文件”选择已有的看图、播放或编辑软件；便携软件同样可用。Linux 直接填写程序完整路径，例如 `/usr/bin/vlc` 或 `/usr/bin/gedit`。需要本机桌面环境，一次选择一个普通文件；编辑器保存会修改原文件，保存后刷新目录可看到变化。选择过期或文件已变化时，需要先刷新重新选择。共享访问者不能启动这台电脑上的程序，可下载原文件后在自己的设备打开。

左侧“快速访问”沿用原来的收藏记录，最多 20 个目录。点击“添加到快速访问”固定当前目录，或右键目录选择“添加到快速访问”，无需先进入；已添加的目录不会重复添加。要取消，在左侧项目上右键选择“从快速访问取消固定”，手机可点项目旁“···”。取消固定只移除导航入口，不会删除原目录。

电脑可按住快速访问项目上下拖动，松开后保存顺序，刷新或重启后仍保留。右键或“···”菜单也提供“移到顶部、上移一位、下移一位、移到底部”，适合手机和键盘操作。保存失败会恢复原顺序并提示；只调整导航顺序，不移动实际文件夹。

快速访问、图标大小、项目间距、默认图标/列表视图、排序方向、每页条数和导航收起状态保存到工具箱数据目录的 `explorer.json`，重启服务或管理页面端口改变后仍会保留。磁盘临时断开不会自动移除入口。共享访问者无法读取或修改本机快速访问列表，其显示偏好只保存在自己的浏览器中。

快速访问和标签页遇到同名目录时，会直接显示盘符或上级路径，例如 `download · E:`、`download · F:`；同盘同名目录则补充能区分它们的上级目录。完整路径仍可悬停查看。共享标签只显示共享名称及共享内路径，不显示这台电脑的磁盘路径；不同目录不会仅靠悬停提示区分。

升级时会尝试迁移当前页面来源中可读取的旧收藏。浏览器隔离不同端口的存储，之前端口下无法读取的旧收藏需要重新添加。使用自定义 `-data` 时请继续使用同一数据目录；备份设置时应妥善保管其中的本机路径，不要随发布包分发给其他人。保存失败会在页面提示，不会把失败的收藏显示为已保存。

### 标签页与刷新恢复

地址栏上方提供页内标签，最多 20 个。点击 `＋` 新建一个打开当前目录的标签，点击 `×` 关闭，至少保留一个。PC 可用鼠标中键打开文件夹到新标签；也可先选择一个文件夹，再点击“新标签打开”，电脑和手机均支持。Ctrl/⌘ 点击现在用于多选。

电脑可拖动标签名称左右换位，不切换当前目录或清空各标签历史。右键标签，或点标签上的“···”，可新建、复制、刷新、向左/右移动、关闭当前、关闭其他或关闭右侧标签。键盘在标签上按 Shift+F10 可打开同一菜单。标签顺序随当前浏览器会话保存，刷新后恢复；与快速访问的长期保存不同。文件写操作期间禁用标签调整，至少保留一个标签。

每个标签分别保留目录、前进/后退记录、搜索条件、排序、图标/列表视图和分页位置。进入子目录后使用“返回”，会恢复原来的分页、视图和滚动位置；“前进”也恢复离开时的位置。切换标签不会改变其他标签的目录；顶部的返回、前进按钮只作用于当前标签。

刷新页面会恢复当前浏览器会话里的标签、选中的标签和已成功进入的目录，保留上次成功进入的目录。状态存放在当前浏览器标签的会话存储中，不包含访问口令、文件勾选、操作指令或上传数据；其他浏览器窗口和其他设备各自独立，默认不保证关闭浏览器标签或工具箱端口变化后仍能恢复；可在通用设置开启长期恢复。

目录被删除、磁盘断开或权限变化导致无法恢复时，会提示并返回可用根目录。内网标签只恢复仍然授权的共享目录，不会按旧路径越过共享范围。刷新仍会中断未完成的上传，已完成文件保留；写操作期间暂时不能切换或关闭页内标签，避免操作错目录。

| 文件 | 可做什么 |
| --- | --- |
| 图片 | JPEG、PNG、GIF、WebP、BMP、AVIF 优先原图显示。HEIC/HEIF、TIFF 等浏览器无法显示时，自动尝试 ImageMagick 兼容预览，最大 2560×2560；缩略图最大 640×480。支持识别后缀与实际编码不一致的图片。兼容预览只生成显示副本，原图可直接下载。 |
| 视频 | MP4、MOV、MKV、AVI、WebM、TS/MTS/M2TS、WMV/ASF、FLV、MPG、3GP 等识别为视频。普通文件优先原始播放；分片 MP4 自动修复播放封装，其他失败可使用“兼容播放”。需要重新编码时按需转换为最高 720p 的 H.264/AAC，原文件不变。[详细格式与性能说明](media-preview.md)。 |
| 音频 | 使用浏览器原生播放器和 HTTP Range；实际编码需设备支持。音频暂不提供实时兼容转换，不支持时下载查看。 |
| PDF | 使用浏览器自带 PDF 查看器；部分手机浏览器需要下载后打开。 |
| 文本、JSON、Markdown、CSV、字幕、代码、HTML/SVG 源码 | 以纯文本显示，最大 1 MiB；支持 UTF-8、GBK/GB18030、UTF-16 编码选择。HTML/SVG 不作为网页执行。 |
| Office 文档、压缩包及其他文件 | 下载后使用相应软件打开，不上传到第三方预览服务。 |

MP4 后缀不代表一定能直接播放，其中的编码也需要设备支持。H.264/AAC 的兼容范围较广；其他情况可使用“兼容播放”，仍失败时下载原文件查看。[浏览器视频编码说明](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Formats/Video_codecs)

图片和视频使用全窗口深色预览：两侧按钮切换上一项/下一项，顶部始终显示当前序号及数量，底部集中提供缩放、倍速和全屏等操作。点击顶部“文件列表”可展开当前页同类资源列表，直接选择文件；电脑在右侧显示，手机以可关闭的侧边面板显示。列表包含缩略图、名称与大小，视频还显示时长。小图与时长按需加载，不批量下载原图或视频；时长与目录列表共用缓存和最多 2 个并发探测，同一视频不重复探测。隐藏侧栏或关闭预览会取消侧栏未完成的读取。关闭预览后释放媒体与列表内容。

图片和视频预览底部提供横向缩略图栏：点击小图直接切换，当前项高亮并显示位置，电脑可滚动、手机可横向滑动；工具栏可隐藏或显示缩略图。兼容视频请使用画面正下方的“全片进度”查看完整时长和跳转；播放器自带进度可能只是当前缓冲片段。缩略图栏展示当前页同类的资源，不混入文件夹、文本或其他类型。图片放大后方向键仍用于移动画面；焦点位于缩略图栏时，方向键用于切换资源。

大图缩略图生成只读取原图，采用 JPEG 解码阶段缩小及时间、缓存、并发限制，不修改原文件。没有 ImageMagick 或超出处理限制时，使用浏览器原图回退可能增加加载流量。缺少解码器、加密或损坏的媒体仍可能无法预览。

## 在手机或其他电脑访问

1. 在运行工具箱的电脑进入“资源管理器”，点击“内网共享设置”。访问设置、共享目录、连接地址分别显示，保存按钮固定在弹窗底部；远程访问和较长说明默认折叠。
2. 点击“选择目录”浏览磁盘和文件夹，可勾选多个目录一起添加，也可选择当前目录或磁盘根目录；仍支持直接输入路径。可修改显示名称，默认**只读**。
3. 设置至少 8 字符的访问口令。勾选“允许修改”后，所有知道口令并已登录的设备都可以在该目录上传、新建、移动、改名和删除。
4. 勾选“开启内网共享（随工具箱启动）”，点击“保存并应用”。默认端口为 `18788`，占用时可改为其他 `1024–65535` 端口。
5. 复制页面生成的地址，在同一内网设备的浏览器打开，输入口令。手机上点左上角按钮切换共享目录。

点击“保存并应用”后会居中弹出结果：保存成功时说明共享已开启或关闭，失败时显示具体原因，部分目录不可用时单独提醒。点击“知道了”或按 Esc 返回设置；原设置页仍保留结果文字，方便继续核对。保存过程中按钮显示“正在保存…”，避免重复提交。

可添加多个共享目录，最多 128 个。内网访客只看到共享名称和相对目录，看不到未共享磁盘的列表或本机完整路径；没有本机批处理、工具设置、常用密码库和共享管理权限。一个口令供所有共享目录使用，每个目录可以单独选择只读或允许修改。

共享使用独立 IPv4 端口，首次使用默认关闭。开启并保存后，每次运行工具箱都会自动恢复共享；取消勾选并保存后，下次启动也保持关闭。目录列表（最多 128 个）、显示名称、各目录权限、口令和端口都会保存在当前数据目录的 `sharing.json` 中；使用 `-data` 时应继续使用同一数据目录。关闭共享不会清空这些设置。停止共享会关闭监听和现有连接；修改共享设置会清除已登录会话，设备需要重新登录。登录最长 8 小时，单个来源每分钟最多尝试 5 次，最多保留 64 个登录会话。

**普通 HTTP 仅用于可信内网或加密组网。**通过已有穿透服务使用公网域名时，请配置 HTTPS 入口与可信代理，保留共享口令；不要使用重要账户的同一个密码，也不要开放工具箱管理页。[组网和内网穿透配置](remote-access.md)。Windows 防火墙询问时仅允许专用网络；工具箱不会自动修改防火墙。口令在电脑本地仅保存随机盐和 PBKDF2-HMAC-SHA256 派生值，使用 600000 次迭代，不保存明文。[口令存储依据](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)

### 不同网络访问：xEdge / ZeroTier 新手教程

例如电脑在家、手机用流量：先在电脑开启上面的共享，再让电脑与手机加入同一个虚拟局域网，最后在手机浏览器打开 **电脑的组网 IPv4 + 共享端口**。手机只需组网客户端和浏览器，不需要安装工具箱。

| 方式 | 简单操作 | 访问示例 |
| --- | --- | --- |
| xEdge 添加终端 | 按控制台/客户端引导将电脑、手机接入同一安全内网，确认两台终端在线，复制电脑组网 IP；来源在 `100.64.0.0/10` 时开启工具箱“允许虚拟组网访问” | `http://100.64.0.10:18788/` |
| ZeroTier 组网 | 创建私有网络，电脑和手机加入同一个 Network ID，在控制台授权两台设备，复制电脑的 Managed IP | `http://10.147.17.10:18788/` |

以上为虚构地址，使用你自己的电脑组网 IP 和实际共享端口。用组网 IP 直连时无需填写 HTTPS 外网地址或可信代理。切换手机到流量后重新访问，出现共享登录页并输入工具箱口令，才能确认跨网络访问成功。

完整分步操作、官方下载入口、两种控制台授权方式及排错，见 **[不同网络访问：新手教程](remote-access-quickstart.md)**。其他组网或穿透产品也可参考[通用配置](remote-access.md)，不必换成指定平台。

## 文件操作规则


- 上传一次可选多个文件，逐个传输，显示进度并支持取消。单文件上限 32 GiB；只发布完成的文件。同名文件不覆盖，失败或取消会尝试清理该文件的暂存数据，已完成的其他文件保留。
- 改名不覆盖同名目标。复制/移动同名目标会要求选择冲突规则；支持同盘与跨盘，内网设备的范围限于当前共享目录，可逐级选择或输入目标目录。
- 删除默认移入**运行工具箱这台电脑**的系统回收站或废纸篓；不同系统支持情况见[跨平台说明](platforms.md)。要永久删除，必须在确认窗口另行勾选。回收站不支持的位置会报告失败，不自动永久删除。
- 删除文件夹会包含其内部内容。回收站中可以通过 Windows 正常恢复；永久删除不可恢复。多项操作逐项执行，中途失败时此前完成的项目保留，先刷新列表再继续。
- 写操作延用系统、配置、凭据、工具箱程序及数据目录的保护。可以浏览磁盘根目录，但不能改名或删除根目录本身；支持共享整个磁盘或文件系统根目录，但受保护的系统、配置、凭据、工具箱程序与数据内容会被隐藏并拒绝直接读取。共享根目录本身也不能被内网设备改名、移动或删除。
- 不跟随符号链接或目录联接。共享时记录根目录身份；写操作还核对列表选择时的文件身份、大小和修改时间。选择超过 15 分钟、文件被替换或发生变化时，需要刷新后重新选择。

这些检查用于减少误操作，不是对同一账户下恶意程序的沙箱。请勿同时移动共享根目录、用批处理改名同一批文件或让其他程序替换它们；重要资料仍应另有备份。缩略图使用有限内存缓存，并可保存到数据目录的磁盘缓存（默认上限 256 MB，可关闭或清理），不修改原图；视频播放读取原文件，电脑需保持开机及资源磁盘可用。

## PC 与移动端操作

PC 使用固定侧栏、地址栏和图标/列表视图；图片可用方向键切换。手机将目录导航放入抽屉，工具按钮适合触控，图片和视频使用全屏预览，图片可以左右滑动；不依赖右键或鼠标悬停。实际图片和视频解码能力仍取决于手机系统、浏览器及文件格式。

可用仓库的 [体验素材](../samples/README.md)练习：先运行 `try-samples.cmd` 创建独立副本，再用文件浏览打开该目录。首次共享建议只添加一份体验副本，并保持只读，确认访问正常后再根据需要开放修改。

## 连接问题

- 手机与电脑需要在同一可互访网络。访客 Wi-Fi、AP 隔离或 VPN 可能阻止访问。
- 有多个地址时，选正在使用的 Wi-Fi 或有线网卡地址；虚拟网卡或 VPN 地址不一定可达。
- 检查端口是否被占用、Windows 防火墙是否允许当前程序和专用网络。不要为解决访问问题关闭整个防火墙。
- 播放只有声音、黑屏或提示编码不支持时，先下载原文件检查；兼容播放会在界面提示，必要时按需转成最高 720p，原文件不变。
- 工具箱需要保持运行。启用自动共享后，重启会继续使用已保存的端口和目录，其他设备仍需输入口令登录；电脑内网 IP 未变化时可继续使用原地址。IP 由路由器分配，建议在路由器为电脑保留固定 IP。
- 共享端口被占用时不会自动换端口，以免原访问地址悄悄改变；本机共享设置会显示失败原因，释放端口或修改端口后重新保存即可。
- 其他程序的对外连接也可能占用本地端口，不能只查监听服务。错误提示会区分“服务或对外连接占用”和“系统保留/权限限制”，并保留底层错误。更换端口后，已有代理或穿透配置中的转发目标也需同步更新。
- 磁盘离线或目录不可用时，保留原目录配置并提示，其他可用目录仍共享；离线目录不会出现在访客列表。连接磁盘后在本机重新保存共享设置，或重启工具箱以恢复。Windows 登录自启是独立选项，默认关闭，可在安装时或“通用设置 → 启动”开启；程序不会自动重试重新接入的磁盘。

手机数据流量访问：支持开启虚拟组网地址访问，也可配置现有 HTTPS 域名穿透；详细设置见[远程访问](remote-access.md)。

## 显示与性能

图标视图右侧点击“显示 → 图标大小与间距”：图标大小调整 140–420 像素的卡片宽度；项目间距调整横向与纵向空隙，范围 0–32px，默认 16px，向左更紧凑。两项独立设置，拖动即时生效，不重新扫描。刷新后保留，本机重启也会保留；共享访问者仅保存到自己的浏览器。列表视图不受影响。手机也可调整，宽卡片会自动排成适合屏幕的列数。

图片预览支持滚轮缩放、双击放大/还原、放大后拖动，以及“适应窗口”“原始大小”按钮。手机支持双指缩放、拖动与双击；适应窗口时左右滑动切图。键盘 `+`/`-` 缩放，`0` 适应窗口，放大时方向键平移；适应窗口时左右方向键切换图片。

视频显示可用封面，支持播放速度与全屏；上一项/下一项只切换视频。图片、视频和音频分别连续浏览。浏览器编码支持仍有限制，缩略图能生成并不代表浏览器一定能播放原视频。

共享目录数量上限提高到 128 个；共享根目录时仍默认只读，不改变批量格式化、改名等工具的根目录安全限制。

移动目标目录选择器仅列目录并支持分页；加载新目标期间不能执行移动，旧请求不会覆盖当前目标。移动或删除未全部完成时会刷新目录，已经完成的操作保留，请核对后重新选择剩余项目。

## 搜索、连续预览与工具联动

大目录按批次读取完整项目后进行自然排序与分页，不再截断到前 20000 项；短时目录快照减少连续翻页的重复读取，手动刷新会强制重新扫描。勾选“含子目录”后，有搜索文字时递归检索，目录链接不跟随；可用“取消读取”终止。首次读取大型或网络目录仍可能需要等待。

图片和视频在当前页没有同类下一项时，会读取后续页并跳过没有同类文件的页面；上一项也支持跨页。关闭预览会取消尚未结束的跨页读取。当前缩略图栏展示本页项目，完整目录通过两侧按钮连续浏览。

本机目录的右键菜单提供“使用工具箱处理…”，空白处可处理当前目录。选择功能后带入目录，仍需扫描预览并确认执行；不会直接改动文件。共享访客没有此入口。

## 复制、移动与上传

选中项目后，可使用顶部或右键菜单的“复制、剪切”；顶部持续显示已复制/剪切的数量。进入目标目录点击顶部“粘贴”，或右键目标文件夹选择“粘贴到此目录”，无需寻找列表空白；仍可使用空白处右键、Ctrl/⌘+C/X/V，以及“复制到”“移动”选择目标。输入框保留正常文字剪贴板操作，文件剪贴板仅在当前资源管理器页面内有效。同名目标需明确选择保留两份、合并并跳过或替换并备份。本机支持跨盘；共享操作始终受当前共享范围和修改权限约束。

跨盘移动先复制到临时位置，校验副本内容及源目录变化后发布，再删除源文件。取消或失败时保留源文件；如果副本已发布而源文件清理未完成，会提示核对两处结果。传输期间显示进度，可取消。

“更多 → 上传文件夹”保留浏览器提供的相对路径；也可拖入文件或文件夹，支持保留拖入的空目录。文件夹选择器通常不提供空目录。单文件上限 32 GiB，分段上传不一次读取整个文件到内存。同名文件不覆盖，其他文件可继续上传，结束显示未完成项。

网络中断、刷新或重启后，重新选择相同文件/文件夹和目标目录，会根据文件指纹接续已有内容。浏览器不会在刷新后自动重新获得本地文件权限。断点保留 7 天，过期内容在后续上传时清理；只读共享不可上传。相同文件应保持名称、大小、修改时间及内容不变。

## 通用设置与缓存

本机两处页面均可打开通用设置：默认播放器、自动播放、静音、播放位置记忆、字号、重启恢复标签、任务弹窗/声音、缩略图磁盘缓存，以及 Windows 登录自启（默认关闭）。页面底部“关于与更新”可查看版本和打开发布列表，见[安装说明](installation.md)。开启恢复标签后，本机管理页保存最后使用的目录、排序、分页和滚动位置，可跨服务重启及端口变化恢复；多个本机窗口以最后保存的状态为准，旧的前进/后退记录仍限当前浏览器会话。共享访客继续使用自己的浏览器会话。播放位置默认不记录；启用后最多记住 500 项。

缩略图除内存缓存外，可保存到数据目录的 `thumbnails`，默认上限 256 MB，自动淘汰旧缓存；设置 0 关闭磁盘缓存。“清空缩略图缓存”不会删除源图片或视频。文件内容大小或修改时间变化后使用新缓存键。
