本页记录当前完整功能基线的实现边界，供维护者排查和验证，不是发布日志。测试使用合成资源；使用方法见操作指南，具体测试入口见 [测试指南](testing.md)。

## 当前实现

| 范围 | 改进 |
| --- | --- |
| 目录统计命名 | 普通模式也在执行前复核目录结构、媒体数量和大小；内容变化时要求重新预览，避免写入旧统计。清理模式保留清理后的复核 |
| 统计、改名、编号、媒体信息命名 | 改用系统“不覆盖目标”接口，消除 Linux/macOS 中检查目标后、实际改名前被并发创建同名目标的覆盖窗口 |
| 图片压缩 | 所有可压缩格式都检查输入/输出可读取性、帧数、编码与尺寸；JPEG/WebP 正常自动方向旋转可交换宽高，PNG 不允许改变宽高 |
| JPEG 别名 | 明确使用 JPEG 编码写入 JPG/JPEG/JPE/JFIF，避免只依赖后缀识别编码；导出的原生命令使用相同参数 |
| 视频元数据 | MP4/MOV/M4V/QT 清理后补齐轨道数量、编解码信息、尺寸、音频参数、章节数量和时长复核 |
| 移动目录选择器 | 隔离慢请求，加载期间禁用移动，只列目录并支持分页，避免旧请求覆盖新目标或文件挤占目录名额 |
| 输入、移动和共享目录选择器 | 手动修改地址后先禁用当前目录选择，确认新地址后再允许操作；通用工具选择器也隔离旧请求，避免界面地址与实际选择目录不一致 |
| 目录读取 | 客户端取消或切换目录后，后端停止继续遍历和生成选择标识，减少大目录中的无效工作 |
| 文件移动和删除 | 中途失败后关闭失效窗口、刷新目录并提示核对剩余项目，避免选择已清空后再次点击呈现空操作成功 |
| 共享状态提示 | 保存后保留后端失败原因，并区分关闭自动启动与设置已保存但当前未启动 |
| 收藏和显示偏好 | 本机收藏、图标大小及默认视图保存到工具箱数据目录；不随随机管理端口变化而丢失，支持旧收藏迁移、失败提示与共享访问者隔离 |
| 资源选择与导航 | 默认隐藏缩略图勾选框，提供选择模式及电脑多选快捷键；本机有明确的返回工具箱与打开系统文件管理器入口，侧栏减少留白并保留可读字号 |
| 大图缩略图与预览 | 超过 2400 万像素的 JPEG 使用 ImageMagick 在解码时缩小，保留资源限制；全部图片增加原图回退，预览底部增加可折叠的图片/视频缩略图栏 |
| 同名目录辨识 | 收藏和标签页直接显示盘符或可区分的上级路径；共享路径仅使用共享名称和相对路径，窗口变窄时保持当前标签可见 |
| 浏览交互与媒体信息 | 单击选择/双击打开，右键属性读取尺寸与时长；返回恢复分页和滚动位置；主列表和预览侧栏按需读取视频时长，最多 2 个并发，共用缓存及进行中的请求，关闭取消 |
| 原生窗口与品牌 | mpv 原生图片/视频窗口、独立控制与实际硬解状态；统一动漫仓鼠品牌图与 Windows/浏览器图标 |
| 媒体兼容与性能 | 视频封面和元数据改用可随机读取的文件句柄，避免分片 MP4 索引超时；提供按需封装修复和 H.264/AAC 兼容播放、跳转、图像格式回退及受限的 LRU 缓存与并发处理 |

回归测试覆盖统计变化、并发抢占同一改名目标、图片格式/尺寸异常、移动目录慢请求与分页、失败后的界面恢复。实际媒体验证使用 ImageMagick、FFmpeg/FFprobe、ExifTool；随包自测覆盖主要批处理流程。

## 各功能检查范围

| 功能 | 主要边界 |
| --- | --- |
| 目录统计命名 | 旧统计格式、排除目录、递归范围、非媒体清理、执行前内容变化 |
| 批量重命名 | 文字/示例/正则、前后缀、名称合法性、同名冲突、并发保护 |
| 目录连续编号 | 仅编号、自定义模板、自然排序、续号、编号占用和上限 |
| 媒体信息命名 | 依赖缺失、读取失败、原信息后缀更新、文件变化与目标保护 |
| 清理元数据 | 格式筛选、副本输出、轨道/章节/时长、原件保护 |
| PDF 图册索引 | 中文字体、无封面目录、临时页面、PDF 结构与已有输出保护 |
| 图片压缩 | 格式选择、动画跳过、PNG 编码、透明度与尺寸、未变小跳过 |
| 视频压缩 | 模式、编码能力、CPU 回退、旧 FFmpeg 参数、结果校验、取消与进度 |
| 视频缩略图拼图 | 网格参数、短片、时间文字、字体、尺寸、MPEG-TS 快速定位空帧及兼容重试、原件保护 |
| 打包资源 | 模式、附加文件、分卷、密码、标记、源内容变化和结果校验 |
| 解压资源 | 数字后缀分卷与真实格式识别、实时阶段进度、密码错误、路径越界、同名规则、原包清理时机 |
| 文件去重入口 | 路径检查、GUI/CLI 区分与平台程序版本；不会自动调用外部软件删除重复文件 |
| 资源管理器与共享 | 首次登录静态资源加载、会话与错误提示、读写权限、根目录、选择过期、标签、图片缩放、代理来源 |
| 私密笔记 | 加密与损坏拒绝、密码/动态码、刷新会话失效、附件与备份完整性、历史/回收站、草稿、编辑锁、全屏/侧栏、手机布局与大列表 |
| CLI 与跨平台 | 参数说明、命令转义、密码环境变量、POSIX 命令与各平台构建 |

这些检查不代表所有硬件、媒体编码、第三方版本和网络环境都已实测；macOS 当前仍缺少真机验证。

## 任务历史与恢复边界

已保存升级后的网页执行参数、汇总、日志和四类独立媒体任务的逐项结果；中断提示、失败/未完成项定向重扫、输出保护及历史分页见[任务历史](task-history.md)。改名等有顺序依赖的工具只载入参数，不直接重放旧计划；未实现文件内断点续压或全局撤销。

## 当前未提供的能力

- **长期目录索引**：已支持完整读取、短时目录快照、子目录搜索与取消；独立的长期索引数据库和文件系统监听仍未提供。
- **常用压缩密码列表的跨平台系统加密、更多硬件覆盖**：该列表目前依赖 Windows 账户加密，区别于已支持跨平台备份的私密笔记；macOS VideoToolbox、Linux VAAPI 视频压缩尚未接入。

已扩展：独立媒体任务并发、文件夹/分段续传、校验复制与跨盘移动、跨页媒体预览、持久缩略图缓存、通用设置及跨管理页面的任务提醒。视频压缩保留源时间基准，避免可变帧率舍入产生重复 DTS。
